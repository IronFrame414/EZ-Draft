# Phase 5 · Ceilings / RCP

Goal: edit each room's ceiling and the objects on it, and produce the reflected ceiling plan data for sheet A6.0.

**Build gate:** a fixture room with a sloped ceiling, beams, cans and an ACT area is built by the browser test, and the first half of the RCP acceptance test passes (ACT borders never below half a tile). The second half (lights on E1.0 with the same circuit) closes in EZD-708. **Field check (Josh):** draw the RCP for a real room.
