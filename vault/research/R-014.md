# Findings

## (1) Gemini
- Model id: `gemini-3.1-flash-image` (Gemini 3.1 Flash Image, "Nano Banana 2"). Source: https://ai.google.dev/gemini-api/docs/pricing ("Model ID: `gemini-3.1-flash-image`").
- Input: "$0.50 (text/image)" per 1M tokens (Standard, paid). Source: https://ai.google.dev/gemini-api/docs/pricing.
- Image output: "$60.00 (images)" per 1M tokens; footnote "Image output is priced at $60 per 1,000,000 tokens." Source: https://ai.google.dev/gemini-api/docs/pricing.
- gemini-2.5-flash-image: pricing page says it "is deprecated and will be shut down on October 2, 2026" (https://ai.google.dev/gemini-api/docs/pricing). Deprecations page lists "`gemini-2.5-flash-image` | October 2, 2025 | March 15, 2027 | `gemini-3.1-flash-lite-image`" (https://ai.google.dev/gemini-api/docs/deprecations). The two pages disagree on the shutdown date; the deprecations page gives March 15, 2027 and is the later statement. Not resolved by the official pages.
- gemini-3.1-flash-image deprecations row: "`gemini-3.1-flash-image` | May 28, 2026 | No shutdown date announced | `gemini-nano-banana-2.1`" (https://ai.google.dev/gemini-api/docs/deprecations).
- Input price for gemini-2.5-flash-image: "$0.30 (text / image)" per 1M; output "$0.039 per image" (footnote "$30 per 1,000,000 tokens") (https://ai.google.dev/gemini-api/docs/pricing). Not needed if 2.5 is not used.

## (2) OpenAI GPT Image 2
- Model id: `gpt-image-2`. Source: https://developers.openai.com/api/docs/models/gpt-image-2 ("Model ID: `gpt-image-2`").
- Endpoint: "| Image edit | `v1/images/edits` | Supported |" (https://developers.openai.com/api/docs/models/gpt-image-2).
- Standard price per 1M tokens: "gpt-image-2 | Image | $8.00 | $30.00 | $2.00" (columns: input, cached input, output per the page's table header); "gpt-image-2 | Text | $5.00 | - | $1.25". Source: https://developers.openai.com/api/docs/pricing. So image input $8.00, image output $30.00, text input $5.00 per 1M.
- Batch price: image input $4.00, image output $15.00, text input $2.50 per 1M (https://developers.openai.com/api/docs/pricing).
- The pricing page says "For image generation cost estimates, use the calculator in the image generation guide." (https://developers.openai.com/api/docs/pricing). Per-image prices: not found.
- Conflict: the image generation guide (https://developers.openai.com/api/docs/guides/image-generation) uses `"gpt-image-2.5-sunburst"` in every `images.edit` and cURL example (`-F "model=gpt-image-2.5-sunburst"`), and says "`gpt-image-2.5-sunburst` and `gpt-image-2.5-flare`" are the two supported models. The guide does not mention `gpt-image-2` by itself. Pricing lists gpt-image-2.5-sunburst and gpt-image-2.5-flare at the same rates as gpt-image-2 (https://developers.openai.com/api/docs/pricing).
- Both `gpt-image-2` (model page) and `gpt-image-2.5-sunburst` / `gpt-image-2.5-flare` (guide) are named in official pages. Which one the edits endpoint accepts is stated by the guide for 2.5 and by the model page for `gpt-image-2`.

## (3) Flux Kontext pro (BFL)
- Endpoint: `https://api.bfl.ai/v1/flux-kontext-pro` (quoted from the create request example on https://docs.bfl.ai/kontext/kontext_text_to_image). Model id as a separate string: not found.
- Price per output image: not found. https://docs.bfl.ai/kontext/kontext_text_to_image shows no price. https://bfl.ai/pricing (the docs.bfl.ai/pricing address redirects there) lists model names FLUX 3 Image, FLUX 3 Image Klein, FLUX.2 [flex], [pro], [max], [klein] 4B and 9B, FLUX Outpainting, FLUX Eraser, FLUX VTO. It does not list Flux Kontext. Its only per-image rate is "Rate:$0.048 / image" in the calculator, not tied to a model name.
- Kontext max: not found on the Kontext page.
