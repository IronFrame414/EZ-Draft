# Findings (as of 2026-10-19)

## 1. Resend send email (REST)
- Endpoint: `POST https://api.resend.com/emails`. Source: https://resend.com/docs/api-reference/emails/send-email
- Auth header: `Authorization: Bearer re_xxxxxxxxx`. Source: https://resend.com/docs/api-reference/emails/send-email
- Body, required: `from`, `to` (string or array of strings), `subject`. Optional: `html`, `text`, `reply_to` (string or array). Source: https://resend.com/docs/api-reference/emails/send-email
- Success body: `{"id": "<uuid>"}`. The send page does not state the status code. The API introduction lists `200` as "Successful request" for the API generally: https://resend.com/docs/api-reference/introduction
- Error body `statusCode`, `name`, `message`: NOT CONFIRMED. The errors page does not show a JSON shape. It lists error names with status codes and says "Resend uses standard HTTP response codes for success and failure notifications." Examples: `validation_error` (400, 401, 403), `missing_required_field` (422), `rate_limit_exceeded` (429), `restricted_api_key` (401, 403), `application_error` (500). Source: https://resend.com/docs/api-reference/errors

## 2. Resend SMTP
- Host `smtp.resend.com`; username `resend`; password `YOUR_API_KEY`. Source: https://resend.com/docs/send-with-smtp
- SMTPS (implicit TLS): ports 465 and 2465. STARTTLS: ports 25, 587, 2587. Source: https://resend.com/docs/send-with-smtp
- Recommended port: the SMTP page names none. The SMTP search summary said "if you don't know which port to use, we recommend 465," but that text was not in the fetched page. Treat 465 as unverified recommendation: https://resend.com/docs/send-with-smtp

## 3. Resend dashboard
- API key permissions: "Full access" (create, delete, get, update any resource) and "Sending access" (only send emails). Source: https://resend.com/changelog/new-api-key-permissions
- Domain restriction: only for "Sending access"; you choose one domain. Source: https://resend.com/changelog/new-api-key-permissions and https://resend.com/docs/create-an-api-key
- Key creation button: "Create API Key" on the "API keys" dashboard page. Source: https://resend.com/docs/create-an-api-key
- Domains menu: the docs call it the "Domains Dashboard page" and do not give the sidebar label. Add-domain button label: NOT CONFIRMED. Source: https://resend.com/docs/dashboard/domains/introduction

## 4. Supabase custom SMTP
- Location: Authentication settings page, SMTP settings. Direct link given: https://supabase.com/dashboard/project/_/auth/smtp (replace `_` with the project ref). Source: https://supabase.com/docs/guides/auth/auth-smtp
- Click path (Authentication > Notifications > Email > SMTP Settings): from a partner page, not Supabase docs: https://supabase.com/partners/catalog/autosend
- Dashboard field labels: NOT CONFIRMED by the official page. Management API field names (confirmed): `smtp_admin_email` (sender email), `smtp_sender_name`, `smtp_host`, `smtp_port`, `smtp_user`, `smtp_pass`. Example port `587`. Source: https://supabase.com/docs/guides/auth/auth-smtp and https://supabase.com/docs/reference/api/v1-update-auth-service-config
- Also: turn off link tracking at the SMTP provider. Source: https://supabase.com/docs/guides/auth/auth-smtp
