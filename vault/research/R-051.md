# Findings

1. Vercel limit: "The maximum payload size for the request body or the response body of a Vercel Function is **4.5 MB**. If a Vercel Function receives a payload in excess of the limit it will return an error 413: `FUNCTION_PAYLOAD_TOO_LARGE`." Source: https://vercel.com/docs/functions/limitations (section "Request body size", last_updated 2026-08-24).
2. Error page: HTTP status `413` (Payload Too Large), "occurs when the payload sent to a function exceeds the maximum allowed size", and it points to the "limit of 4.5MB". Source: https://vercel.com/docs/errors/FUNCTION_PAYLOAD_TOO_LARGE
3. Bytes: the docs state no byte figure. "4.5 MB" is not defined as 4,500,000 or 4,718,592 bytes on any page read. Sources checked: https://vercel.com/docs/functions/limitations, https://vercel.com/kb/guide/how-to-bypass-vercel-body-size-limit-serverless-functions
4. KB page: "Request body: 'This is when the body sent from the user/client to the function exceeds the 4.5 MB limit.'" No bytes figure, no plan or runtime qualifier given. Source: https://vercel.com/kb/guide/how-to-bypass-vercel-body-size-limit-serverless-functions
5. Response side: the limitations page states the same 4.5 MB figure for the response body. The KB page cites a "500 - FUNCTION RESPONSE PAYLOAD TOO_LARGE" error for oversized responses. Sources: https://vercel.com/docs/functions/limitations, https://vercel.com/kb/guide/how-to-bypass-vercel-body-size-limit-serverless-functions
6. Region: the limitations page says functions run "in a single region by default (`iad1`)", and it gives no region-specific body limit. Source: https://vercel.com/docs/functions/limitations
7. Next.js Route Handlers: the route file-convention page (https://nextjs.org/docs/app/api-reference/file-conventions/route, lastUpdated 2026-04-30) states no request body size limit. Its Request Body example is `await request.json()`. The page documents no default limit for `request.arrayBuffer()`.
8. Next.js Server Actions: "By default, the maximum size of the request body sent to a Server Action is 1MB ... you can configure this limit using the `serverActions.bodySizeLimit` option." Source: https://nextjs.org/docs/app/api-reference/config/next-config-js/serverActions (lastUpdated 2026-08-26). The page describes this limit only for Server Actions and does not mention Route Handlers.
9. Scope gap: I did not fetch the Next.js 15 or 16 versioned pages, or the proxy/middleware body-size page. I did not find a Route Handler body limit in the pages I read.
