REPORT FINDINGS (EZD-373, 2026-11-10)

Q1a. FontFaceSet.load rejects on the first failing matched face. Chromium LoadFontPromiseResolver::NotifyError calls resolver_->Reject(font_face->GetError()) on the first error; NotifyLoaded resolves only when all faces load. https://raw.githubusercontent.com/chromium/chromium/main/third_party/blink/renderer/core/css/font_face_set.cc
  Spec: step 3 rejects with SyntaxError only for unparsable font strings; failed face loads are not spelled out. https://www.w3.org/TR/css-font-loading-3/
  NetworkError default: FontFace::SetError creates DOMException kNetworkError when no error is passed. https://raw.githubusercontent.com/chromium/chromium/main/third_party/blink/renderer/core/css/font_face.cc
  NOT VERIFIED: the error a local() miss sets (LocalFontFaceSource file was 404 or not located). Spec for FontFace.load says NetworkError on load failure (css-font-loading-3 FontFace.load step 5.1).

Q1b. Chromium Linux local() matching uses only PostScript name, then full name. FcFontList with FC_POSTSCRIPT_NAME or FC_FULLNAME; no FC_FAMILY, no FcFontMatch alias substitution. TODO crbug.com/40590471 notes matching in any language. https://raw.githubusercontent.com/chromium/chromium/main/components/services/font/fontconfig_matching.cc and https://raw.githubusercontent.com/chromium/chromium/main/third_party/blink/renderer/platform/fonts/linux/font_unique_name_lookup_linux.cc
  Implication: local("Arial") matches only a font whose full or PostScript name is Arial. Liberation Sans does not match by this path.

Q2. No source fetched lists an installed font with full name Arial on ubuntu-24.04. Runner readme font entries: fonts-noto-color-emoji only. No mscorefonts or ttf-mscorefonts-installer. https://github.com/actions/runner-images/blob/main/images/ubuntu/Ubuntu2404-Readme.md
  Playwright nativeDeps ubuntu24.04 tools array: xvfb, fonts-noto-color-emoji, fonts-unifont, fonts-liberation, fonts-ipafont-gothic, fonts-wqy-zenhei, fonts-tlwg-loma-otf, fonts-freefont-ttf. No ttf-mscorefonts. https://raw.githubusercontent.com/microsoft/playwright/main/packages/playwright-core/src/server/registry/nativeDeps.ts
  NOT VERIFIED: whether install-deps for chromium installs the tools array; the code that does so was not in the fetched file.
  Caveat: the readme lists installed apt packages but was not checked for every package; a runner-side fc-list check is the only proof.

Q3. Next.js next/font/local: adjustFontFallback default is 'Arial' (docs). https://nextjs.org/docs/app/api-reference/components/font
  Docs: style.fontFamily includes "fallback fonts"; CSS variable example says the text uses the font and "the generated font fallback". https://nextjs.org/docs/app/api-reference/components/font
  Source: loader.ts emits @font-face font-family = variableName with src url(...); it returns fallbackFonts and variable separately; fallback metrics come from get-fallback-metrics-from-font-file.ts. https://raw.githubusercontent.com/vercel/next.js/canary/packages/font/src/local/loader.ts
  get-fallback-metrics-from-font-file.ts contains name 'Arial' and the text src: local(Arial) only inside a doc comment. https://raw.githubusercontent.com/vercel/next.js/canary/packages/font/src/local/get-fallback-metrics-from-font-file.ts
  NOT VERIFIED: the code that emits the fallback @font-face with local(Arial), and how className or variable values are composed (caller not located). The KNOWN claim that get-fallback-metrics-from-font-file emits local(Arial) is not supported by the fetched source.
