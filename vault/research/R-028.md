Q3 setting db-pre-request. PostgREST docs (https://docs.postgrest.org/en/v12/references/configuration.html): db-pre-request is reloadable; in-database name `pgrst.db_pre_request`. Reload is by `NOTIFY pgrst, 'reload config'` or SIGUSR2. The page says "Any modification to the In-Database Configuration will be applied during reload." It also says ALTER ROLE authenticator SET pgrst.* settings are "no longer recommended because it requires SUPERUSER", and recommends a pre-config function instead.
- Supabase docs: the custom-claims/RBAC page (https://supabase.com/docs/guides/database/postgres/custom-claims-and-role-based-access-control-rbac) does not mention pgrst.db_pre_request or alter role authenticator. No Supabase page documenting this pattern was found.
- Management API `/v1/projects/{ref}/postgrest` fields and the dashboard: no documented pgrst or db-pre-request field found. The API reference fetch returned 404. Not verified.

Q4 restart and versions.
- No Supabase doc found on whether PostgREST restarts with a database restart or reconnects. Not verified.
