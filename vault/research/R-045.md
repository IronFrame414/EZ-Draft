1. PreToolUse tool_input, Grep (hooks page): pattern (regex, no "Optional" label), path (Optional), glob (Optional), output_mode (default files_with_matches), -i (boolean), multiline (boolean). Source: https://code.claude.com/docs/en/hooks
2. Grep fields not in the hooks table: type, head_limit, offset. The tools reference names type, head_limit and offset as Grep parameters. Source: https://code.claude.com/docs/en/tools-reference
3. PreToolUse tool_input, Glob (hooks page): pattern ("Glob pattern to match files against"), path (Optional, defaults to cwd). Source: https://code.claude.com/docs/en/hooks
4. Requiredness: the hooks page says "The tool_input fields depend on the tool" and marks only path and glob as optional for Grep. It does not mark pattern as required. Not documented beyond this.
5. Grep and Glob are absent from the default tool set on macOS, Linux and WSL. Claude searches with find and grep through Bash, and those searches reach hooks and permission rules as Bash calls. Source: https://code.claude.com/docs/en/tools-reference
6. Grep is built on ripgrep. "Grep respects .gitignore, so gitignored files are skipped." Source: https://code.claude.com/docs/en/tools-reference
7. Glob: "Glob doesn't respect .gitignore by default, so it finds gitignored files alongside tracked ones." Set CLAUDE_CODE_GLOB_NO_IGNORE=false to change this. Source: https://code.claude.com/docs/en/tools-reference
8. Hidden dot-files (.env) for Grep and Glob: not documented in the tools reference or the permissions page. Third-party reports (anecdotal, not official) say rg runs with hidden files included. Source: https://github.com/anthropics/claude-code/issues/26286 and https://github.com/anthropics/claude-code/issues/44868
9. Read deny rules and search tools: "Grep and Glob search the directory the path argument resolves to. Claude Code applies Read deny rules to that directory." Source: https://code.claude.com/docs/en/permissions (Symlinks section, Read and Edit)
10. Best-effort wording: not confirmed in the fetched permissions text. A search summary says Claude "makes a best-effort attempt to apply Read rules" to Grep and Glob, but I did not verify this sentence on the page. Source of the summary: https://code.claude.com/docs/en/permissions (search result, unverified).
11. Permissions table lists "File reads, Grep" as read-only. Source: https://code.claude.com/docs/en/permissions
12. PreToolUse hook decisions do not bypass deny rules. A hook exiting with code 2 blocks the call before permission rules run. Source: https://code.claude.com/docs/en/permissions (Extend permissions with hooks)
13. Matcher: only letters, digits, _, -, spaces, commas and | give an exact string or a list of exact strings. Any other character makes it a JavaScript regex, unanchored. So "Read|Bash|Grep|Glob" is an exact list, not a regex, and it matches exactly those four tool names. Source: https://code.claude.com/docs/en/hooks (Matcher patterns)
14. For PowerShell, the tools reference says to match "Bash|PowerShell" in hooks that inspect shell commands. Source: https://code.claude.com/docs/en/tools-reference (PowerShell tool)
