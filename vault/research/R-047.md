# Findings

1. agent_id / agent_type: documented as common input fields present when a hook fires inside a subagent; subagent type overrides --agent. https://code.claude.com/docs/en/hooks . Issue #86405 (reporter on 2.1.231; maintainer could not reproduce on 2.1.233) shows PreToolUse payloads for subagent Bash/Read calls carrying agent_id and agent_type, and the parent Agent launch event with both null. https://github.com/anthropics/claude-code/issues/86405 . Issue #40140 (opened 2026-03-28, no version named) reported the opposite: only SubagentStart/SubagentStop carried them; closed as not planned by inactivity bot, no maintainer fix. https://github.com/anthropics/claude-code/issues/40140 . No version where the field was introduced was found.
2. transcript_path: documented only as "Path to conversation JSON", with no subagent variant described. https://code.claude.com/docs/en/hooks . Field agent_transcript_path not found in the hooks reference. Whether it points to the parent or subagents/agent-<id>.jsonl is not documented.
3. cwd: documented as "Current working directory when the hook is invoked"; worktree behaviour: cwd is the worktree root after Claude enters a worktree. https://code.claude.com/docs/en/hooks . Issue #40140 notes a cwd-based workaround that "only works with isolation: worktree". https://github.com/anthropics/claude-code/issues/40140 . Docs do not say a subagent's cwd can be set to an arbitrary directory at launch. Not documented.
4. SubagentStart: exists (event 13 of 33 in hooks reference). https://code.claude.com/docs/en/hooks . Its specific input schema (agent_id, agent_type, prompt) is not confirmed on the fetched page (truncated). Matcher filters on agent type; cannot block; exit 2 shows stderr only. https://code.claude.com/docs/en/hooks . Linking SubagentStart output to later PreToolUse calls: not documented; feature request #100198 asks for parent_agent_id on SubagentStart, no implementation found. https://github.com/anthropics/claude-code/issues/100198 .

Not verified: prompt field in SubagentStart input; any changelog entry introducing agent_id.
