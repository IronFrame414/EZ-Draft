# Findings

1. Pushes after auto-merge is enabled. Docs say auto-merge is disabled if someone without write permissions pushes new changes to the head branch or switches the base branch. Pushes by users with write access are not listed as disabling it. The docs do not explicitly say a new head is merged once required checks pass. Source: https://docs.github.com/en/pull-requests/how-tos/merge-and-close-pull-requests/automatically-merging-a-pull-request (also surfaced by search: https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/configuring-pull-request-merges/managing-auto-merge-for-pull-requests-in-your-repository). Manual disable: "People with write permissions to a repository and pull request authors can disable auto-merge for a pull request." Same first URL.

2. expectedHeadOid on enablePullRequestAutoMerge. NOT SETTLED. The GraphQL mutations index (https://docs.github.com/en/graphql/reference/mutations) is index-only; the pulls reference page was not reachable through the fetch tool. No schema description was quoted. Unverified in gh source: whether the auto-merge path also sends expectedHeadOid.

3. mergePullRequest expectedHeadOid. NOT SETTLED from docs. gh source shows the value passed as expectedHeadOid in the merge payload: https://github.com/cli/cli/blob/trunk/pkg/cmd/pr/merge/merge.go (`expectedHeadOid: m.opts.MatchHeadCommit`). The refusal-on-mismatch behaviour is not stated in any fetched source.

4. gh pr merge --disable-auto. Exists. Help text: "Disable auto-merge for this pull request" (https://cli.github.com/manual/gh_pr_merge). Source: `disableAutoMerge` short-circuits before merge checks, and is mutually exclusive with --auto and --admin (https://github.com/cli/cli/blob/trunk/pkg/cmd/pr/merge/merge.go).

5. headRefOid. Exists. Listed in the gh pr view JSON fields: https://cli.github.com/manual/gh_pr_view

Flag help text for reference: --auto "Automatically merge only after necessary requirements are met"; --match-head-commit "Commit SHA that the pull request head must match to allow merge" (https://cli.github.com/manual/gh_pr_merge).

# Gaps

- The GraphQL schema descriptions for enablePullRequestAutoMerge and mergePullRequest were not retrievable. Checking https://docs.github.com/en/graphql/reference/pulls or the schema itself would settle items 2 and 3.
- Whether a later push by a write-access user is merged automatically is implied, not stated.
