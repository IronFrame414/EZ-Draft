No Anthropic documentation for this endpoint was found. Everything below comes from third-party code and issue threads.

1. utilization scale: 0–100 percent, not a fraction.
- Source text: "`utilization` = percentage used (0–100), 0 when no active window". Sample values 33.0 (five_hour), 13.0 (seven_day), 1.0 (seven_day_sonnet). https://github.com/Maciek-roboblog/Claude-Code-Usage-Monitor/issues/202
- ohugonnot/claude-code-statusline copies `.five_hour.utilization` as-is into `percent_used` and computes `percent_remaining = 100 - utilization`; no multiplication. https://raw.githubusercontent.com/ohugonnot/claude-code-statusline/main/statusline.sh ; README calls the values percentages https://github.com/ohugonnot/claude-code-statusline
- CodexBar decodes `utilization` as `Double?` and does no conversion in that file. https://github.com/steipete/CodexBar/blob/main/Sources/CodexBarCore/Providers/Claude/ClaudeOAuth/ClaudeOAuthUsageFetcher.swift
- Not verified: a search snippet (no page fetched) said the 0–1 fraction is used in `anthropic-ratelimit-unified-*` response headers, not in the body. Unchecked.

2. resets_at form: ISO 8601 string with UTC offset, e.g. "2026-04-11T07:00:00.528743+00:00" (five_hour), "2026-04-17T00:59:59.951713+00:00" (seven_day). https://github.com/Maciek-roboblog/Claude-Code-Usage-Monitor/issues/202 . CodexBar types it `resets_at: String?`. https://github.com/steipete/CodexBar/blob/main/Sources/CodexBarCore/Providers/Claude/ClaudeOAuth/ClaudeOAuthUsageFetcher.swift
- Null: the window object itself is null when unused (seven_day_opus: null in the same sample, #202). No source read shows `resets_at` itself set to null. Not documented; treat as possibly nullable (CodexBar marks it optional).
- Reset may point at the next window: once a 5h window is fully spent, the endpoint can report the next window's resets_at. https://github.com/realiti4/claude-swap/issues/244
- Unix seconds applies to the stdin `rate_limits` payload of Claude Code v2.1.80+, per a comment in https://github.com/anthropics/claude-code/issues/31637 (`"resets_at": 1775325600`). Not this endpoint. claude-hud issue https://github.com/jarrodwatts/claude-hud/issues/287 shows the same stdin field as an ISO string ("2026-03-23T12:00:00Z"), so the stdin form is not settled by these sources.

3. Top-level keys.
- five_hour, seven_day, seven_day_opus, seven_day_sonnet, extra_usage. https://github.com/Maciek-roboblog/Claude-Code-Usage-Monitor/issues/202 ; CodexBar struct has fiveHour, sevenDay, sevenDayOpus, sevenDaySonnet, extraUsage (same URL as above).
- extra_usage: is_enabled (false), monthly_limit, used_credits, utilization all null in that sample. https://github.com/Maciek-roboblog/Claude-Code-Usage-Monitor/issues/202
- Newer shape: five_hour, seven_day, limits (array). The flat *_opus / *_sonnet keys are absent. limits entries have kind (weekly_scoped), percent, resets_at, is_active, scope (null or {model:{display_name}}). The sample has a duplicate entry with scope null. https://github.com/yetone/magpie/issues/139
- seven_day_oauth_apps and any "others" key: not seen in any source read.
- 429 body: {"error":{"message":"Rate limited. Please try again later.","type":"rate_limit_error"}}; no Retry-After header. https://github.com/anthropics/claude-code/issues/31637

Request headers.
- Authorization: Bearer <OAuth access token>; anthropic-beta: oauth-2025-04-20; User-Agent: claude-code/<version> ("Critical": without it a heavily rate-limited bucket is hit); Content-Type: application/json. https://github.com/Maciek-roboblog/Claude-Code-Usage-Monitor/issues/202
- CodexBar sends Accept and Content-Type application/json, the beta header, and a User-Agent derived from claude-code/ to claude-cli/ with " (external, cli)". It calls `https://api.anthropic.com/api/oauth/usage?cedar_ember=1` and retries without the query on 400, or on 403 without "user:profile". https://github.com/steipete/CodexBar/blob/main/Sources/CodexBarCore/Providers/Claude/ClaudeOAuth/ClaudeOAuthUsageFetcher.swift
- Beta header needed; opscope had sent User-Agent "opscope". https://github.com/stealth-factory/opscope/issues/279
- Frequent 429s reported. https://github.com/anthropics/claude-code/issues/31637
