## Item 3 (revision cloud and delta tags)
- Candidate: ezdxf.revcloud (module of pypi ezdxf, MIT as above). Source: https://ezdxf.readthedocs.io/en/stable/tools/revcloud.html . "Added in version 1.3.0." Functions points(vertices, segment_length, bulge, start_width, end_width), add_entity(layout, vertices, segment_length, calligraphy=True), is_revcloud(entity). Output is an LWPOLYLINE with bulge arcs. DXF only, Python. No delta-tag symbol found.
- Candidate (SVG, arc-corner helper, not a cloud): svg-round-corners, MIT, v0.4.3, published 2024-01-17, https://openapps.pro/packages/svg-round-corners and https://github.com/BrunoFenzl/svg-round-corners . Rounds straight-line corners (M, L, H, V, Z) into A arcs. The README says it is "not yet supported" for curves. It does not place a cloud of arcs along edges.
- Rejected: jreina/polysvg (MIT per repo page; n-gon SVG generator; no arcs confirmed on page).
- Rejected: svg-arc-to-cubic-bezier, svg-arc-center-endpoint (arc math utilities only; not searched further).
- No SVG or canvas revision-cloud repo found in results. No delta/revision tag symbol library found.
