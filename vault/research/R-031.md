# Findings

- Format: `<project-name>-git-<branch-name>-<scope-slug>.vercel.app`, where `<scope-slug>` is the slug (not the name) of the account or team. Source: https://vercel.com/docs/deployments/generated-urls (section "Generated from Git").
- Stability: the branch URL "will always show you the most recent changes for the branch and won't change if you push new commits." Source: https://vercel.com/docs/deployments/generated-urls. The docs' table says it "Points to the latest deployment from that branch and stays the same when you push new commits." Same source.
- Commit URL for contrast: `<project-name>-<unique-hash>-<scope-slug>.vercel.app`, pinned to one deployment. Source: https://vercel.com/docs/deployments/generated-urls.
- Truncation: Vercel shortens a generated URL when the label before `.vercel.app` exceeds the 63-character DNS label limit (RFC 1035). Vercel also shortens a project name that resembles a web domain (for example `www-company-com` becomes `company`), even inside the limit. Source: https://vercel.com/docs/deployments/generated-urls (section "Truncation" and "Anti-phishing protection"). The docs do not give the exact truncated form, so check the URL the dashboard shows.
- Where it shows: the deployment's Overview and Deployments tabs, on the command line after a build, and the "Visit Preview" button in the pull request comment. Source: https://vercel.com/docs/deployments/generated-urls (sections "Viewing generated URLs" and "Generated from Git").
- Deployment Protection: the docs say generated URLs are "publicly accessible by default, but you can configure it to be private using deployment protection." Source: https://vercel.com/docs/deployments/generated-urls. The docs do not state explicitly that protection covers the branch URL on every plan. A community thread reports protection working on the per-deployment link but not the branch link, and a moderator answered that these URLs can be made private. Source: https://community.vercel.com/t/how-can-i-disable-public-access-to-the-always-up-to-date-branch-url/1518 (2024 posts; not an official doc, unverified against current behaviour).
- Not answered by SCOPE: whether Deployment Protection covers the branch URL on our plan. Check the project's Deployment Protection setting in the dashboard.
- Preview Deployment Suffix (replaces `vercel.app`) is Enterprise and Pro only. Source: https://vercel.com/docs/deployments/generated-urls (section "Preview Deployment Suffix").
