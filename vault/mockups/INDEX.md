# Mockups (Studio boards)

Exported Oct 11, 2026 from the EZ Draft design canvas (https://claude.ai/artifact/TTF8cGeHCB3tBEkAWAU6Ex). These 36 Studio boards are the only valid mockups (22 exported Oct 11 from canvas version 1791755641-7309; 14 added and S02, S15, S16 updated the same night from version 1791766660-e6c1). Boards on the Polished, Refined and Layout C pages are superseded and are not included.

- **PNG** (1600 × 1000): compare against the running app in the preview pane.
- **HTML**: exact sizes, colors, spacing and copy. Read the markup; it will not render the same in a plain browser because the design-canvas runtime (`support.js`) is not included.
- S01, S12 and S13 have repeated lists drawn from sample data in the file's `<script>`; their PNGs show one card with `{{...}}` placeholders. Read the script for the sample rows.
- Icons are Material Symbols Outlined; the app ships them as an SVG sprite (spec, App shell).
- Every screen now has a Studio board. S01b (wizard) is drawn as a dialog over S01, so its background shows S01's `{{...}}` placeholders.
- S15 shows 29 permission switches. The S15 spec text says "28" in places, but its own Permission list names 29; the list is what counts.
- S02 footer shows the one tolerance setting from Defaults (decision 30); the 1/8" value is sample data.
