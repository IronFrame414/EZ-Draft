# Mockups (Studio boards)

Exported Oct 11, 2026 from the EZ Draft design canvas (https://claude.ai/artifact/TTF8cGeHCB3tBEkAWAU6Ex). These 22 Studio boards are the only valid mockups. Boards on the Polished, Refined and Layout C pages are superseded and are not included.

- **PNG** (1600 × 1000): compare against the running app in the preview pane.
- **HTML**: exact sizes, colors, spacing and copy. Read the markup; it will not render the same in a plain browser because the design-canvas runtime (`support.js`) is not included.
- S01, S12 and S13 have repeated lists drawn from sample data in the file's `<script>`; their PNGs show one card with `{{...}}` placeholders. Read the script for the sample rows.
- Icons are Material Symbols Outlined; the app ships them as an SVG sprite (spec, App shell).
- Screens with no mockup (New project wizard, Takeoff, Versions and cleanup sheet, Field measurements review, Field tasks, Settings 15a–15h, phone 3D viewer) are built from the spec text (tickets README, rule 6).
