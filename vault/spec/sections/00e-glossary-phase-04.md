# Glossary addendum · Phase 4

Added by spec-check 4 (Q-0568). Definitions only, each from the source named; no new rules. Read with `vault/spec/glossary.md` and addenda 00b to 00d.

| Term | Meaning | Code name | Source |
| --- | --- | --- | --- |
| Finished face | The drywall surface of a wall. Dimensions are to it; what is drawn and typed is the inside finished face. | none yet (EZD-203 plan names it) | 09e; Q-0559 |
| Wall layer | One material in a wall: stud, drywall or tile backer. | none yet (EZD-203 plan names it) | S03 Wall |
| Default wall | The wall a tool draws until Defaults has wall rows: 2x4 stud, 1/2" drywall both sides, 4 1/2" thick, 8' 0" high. | none yet (EZD-203 plan names it) | Q-0558 |
| Join | Where two walls meet and stay connected when one moves. | none yet (EZD-203 plan names it) | 09e |
| Hosted item | A door, window, cabinet or device placed on a wall; it stays put when the wall moves. | none yet (EZD-203 plan names it) | 09e |
| Wall chain | Walls drawn one after another with the Wall tool. | none yet (EZD-210 plan names it) | S03 Wall |
| Closure gap | How far a finished chain's end misses its start, shown when it is more than 1/64" and at most 12". | none yet (EZD-205 plan names it) | Q-0562; Q-0568 |
| Absorb | Changing one wall parallel to the gap so the room closes. | none yet (EZD-205 plan names it) | S02; Q-0568 |
| Out of square | A room kept with its gap on purpose; logged as room.closure_overridden. | `room.closure_overridden` event | 12 Room closure; S02 Events |
| Typed dimension bar | The floating bar at the bottom center of the canvas showing the active tool, its field and the last wall's length. | none yet (EZD-209 plan names it) | S03; Q-0564 |
| Inline length box | The box that opens at the cursor when a number is typed while drawing. | none yet (EZD-209 plan names it) | 04 Measurement entry |
| Turn angle | The Angle field: the size of the turn from the last wall. | none yet (EZD-209 plan names it) | Q-0560 |
| Room rectangle | The tool that makes four walls and a room from a corner and a width and depth. | none yet (EZD-210 plan names it) | S03; 04 Tool rail |
| Snap marker | The mark on the canvas showing what the cursor snapped to. | none yet (EZD-210 plan names it) | S03 Snap; Q-0563 |
| Zoom stack | Zoom in, Zoom out and Fit to screen at the top right of the canvas. | none yet (EZD-207 plan names it) | S03 |
| Blank template | A starting room shape in the New project wizard: Galley kitchen, L-kitchen, 5x8 bath, primary bath; Empty is the choice with no walls. | none yet (EZD-221 plan names it) | S01; Q-0565 |
| Benchmark project | A generated whole-home model of 3,000 objects, used only to measure speed. | none yet (EZD-236 plan names it) | EZD-236; 11 Performance |
