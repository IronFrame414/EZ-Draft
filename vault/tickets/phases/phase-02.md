## Phase 2 · Geometry core + plan editor

Goal: draw and edit existing conditions and a new design in plan with typed lengths, on one parametric model.

**Build gate:** the Measurement entry, Room closure, Wall move and Selection acceptance tests pass as automated tests, and on the benchmark project pan, zoom and a wall drag stay inside the frame budget. **Field check (Josh):** draw an existing kitchen from tape measurements faster than by hand.
