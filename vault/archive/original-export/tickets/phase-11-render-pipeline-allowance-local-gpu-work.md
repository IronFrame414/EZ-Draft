# Phase 11 · Render pipeline + allowance + local GPU worker

Goal: run angle-first AI renders in three tiers, review and approve them in two steps, and track spend in dollars against a self-refilling allowance, using the local GPU worker first.

**Build gate:** the Render acceptance test passes with the stub provider (Generate disabled until an angle is chosen; an unapproved render is never client-ready), and a job goes to the worker protocol when a worker heartbeat is present and to the cloud adapter when it is not. **Field check (Josh):** a photoreal render of a real job runs on the local worker, then on the cloud API with the worker off.
