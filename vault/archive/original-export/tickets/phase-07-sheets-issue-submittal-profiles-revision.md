# Phase 7 · Sheets, issue, submittal profiles, revisions, property appraiser import

Goal: auto-build the sheet set, pass the issue gates, and issue Rev 0 and numbered revisions as PDFs that follow each department's submittal profile.

**Build gate:** the Sheets, Revisions and RCP acceptance tests pass (key shows only used symbols; issue blocked by an orphan flag; check dimension measures true in the exported PDF; an edit after Rev 0 sent to the client becomes Rev 1 with clouds on exactly the changed objects; RCP lights appear on E1.0 with the same circuit), and the PDFs exported under each seeded department profile pass automated checks for page size, file split, file names, bookmarks and size limit. **Field check (Josh):** a set accepted by a building department.
