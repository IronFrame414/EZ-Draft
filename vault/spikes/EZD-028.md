# EZD-028 · Spike: PDF from a drawing list

Verdict: go

## Question the spike answered
Can PDFKit write a true-to-scale 24x36 permit sheet (hatch, arc, embedded fonts, one bookmark, check dimension) from a drawing list inside the production function limits (Q-0027 (a): 300 s, 2 GB)? (R26 R7; 02 PDF out)

## What was tried
pdfkit 0.20.2, fontkit 2.0.4 (pdfkit's own copy), pdf-lib 1.17.1 and pdfjs-dist 6.4.299 for tests, Node v22.23.3. Spike code: spikes/EZD-028-pdf (tests T1-T12 pass, 12/12). Hard-coded 12' x 10' room (spike input, not a decision). EZD-010's woff2 files (Instrument Sans, DM Mono) embed directly; no TTF fallback needed. Default Helvetica is avoided with the `font: null` document option. Marked-content tags `/EZ_<role>` mark each item. Limits emulated locally with `--max-old-space-size=2048` and a 300 s kill (not the real platform; EZD-715 proves that).

## Result
- Room: page 2592 x 1728 pt; check dimension 216 pt (= 12'-0" at 1/48); 31 hatch lines; arc radius 54 pt; 2 embedded fonts; 1 bookmark; not encrypted. 25.5 ms, 97.7 MB max RSS, 16,786 bytes (limits 300 s, 2048 MB).
- Stress (150,000 segments, one page): 235 ms, 379 MB, 2,359,532 bytes; under the limits and the 10 MB PBC per-file limit. Recorded only.
- calc-auditor re-derived every value independently: PASS.
- Not done: the 300 s / 2 GB figures were not re-confirmed on Vercel's limits page (no web access in the builder); they follow Q-0027 (a), Josh's answer.
- Field check (Josh): open spikes/EZD-028-pdf/out/EZD-028-room.pdf; page reads 36 x 24 in; the check dimension measures 3.00 in at 1:1 (12'-0" at 1/4" = 1'-0"). Does not block the next phase (tickets README rule 7).

## Decision
Use PDFKit as planned. Carry-overs:
- EZD-238: drawing-list fields (line from/to, polyline points, arc center/radius/angles in degrees, hatch as pre-clipped segments, text with fontkit width); units 72 pt/in, scale 1/48.
- EZD-715: bundle the font files with the function; pass `font: null`; use `outline.addItem` (the plan's `outline.add` does not exist in pdfkit 0.20.2); marked-content tags for tests.
- Stress PDF `out/EZD-028-stress.pdf` is not git-ignored; do not commit it.
