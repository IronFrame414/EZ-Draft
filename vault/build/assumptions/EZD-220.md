| EZD-220 | Where pins are placed and how they look on the plan | Pins are a Pins section in the Fixtures panel (F), one button per kind; a click places one, always Existing (even in Proposed, where it is then hidden, which the section's hint says). The plan mark is a map pin: a 6" radius circle whose centre is 10" above the point and a 4" stem down to the point, on the Existing layer, drawn after the geometry drawing list (packages/geometry drawing build is held by EZD-422). Boards are waived (Q-0705) | S03 Fixtures; W3; Q-0704 05-screens; Q-0705 |
| EZD-220 | Photo attach and its failure | The photo is attached from the pin's inspector (one pin selected). A failure keeps the pin and shows Retry, which sends only the part left (start, bytes or complete). Offline the upload fails and shows Retry; the pin itself queues in the outbox. The thumbnail loads through GET /api/source-files/{id}/link, which needs only See projects, reads the row through the caller's client and signs only finished `photo` files (so it never opens a cost file) | Q-0704 05-screens, 03-data-model row 3, 10-permissions; 03c:15 |
