| EZD-402 | How a run holds its cabinets | A `cabinet_run` object (host wall or none, start point, axis, name) lists member ids in two ordered rows, `base` and `upper`; order is position. Boxes, fillers, panels, corner treatments and open shelves are run members with status, level and attributes but no geometry of their own (where they stand follows from the run). Trim (toe kick, light rail, crown, valance) is its own object along one row of one run. A tall box stands in the base row. The run has no status; its members do | 03f Objects inside model_json; S04 Data shown; EZD-233 group precedent |
| EZD-402 | What the run total adds | The widths of every member of the base row in order (boxes, fillers, panels, corner treatments, open shelves), so the elevation chain adds to it (AC-EZD-404-2) and EZD-407's "boxes + fillers + panels" holds. Uppers have their own row total. Scribe is not added; it is the sum of the base row fillers' scribe allowances, given beside the total for the fit chip. Demo members still count; a listed id not in the model adds nothing and is reported as missing | EZD-407 row; board S04 chain 3 + 15 + 24 + 36 + 18 + 21 = 117 |
| EZD-402 | What the header counts and "Box N of M" count | The base row's boxes and fillers: board S04 reads "5 boxes · 2 fillers" and "Box 3 of 5" with uppers drawn above. Position counts only boxes of the same row | Board S04; S04 Data shown |
| EZD-402 | Lists the spec leaves open | Face layouts: one door, two doors, drawer + one door, drawer + two doors, false drawer + one door, false drawer + two doors, two, three or four drawers, open, panel.
