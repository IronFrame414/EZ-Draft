# EZD-179 · Fix: app Vitest config loads without the CommonJS warning

- **ACs:** AC-EZD-179-1, AC-EZD-179-2
- **Complexity:** low (section 8)
- **User-visible result:** every Vitest run of the app (from `app/`, from the repo root, and the net-guard probe runs) starts with no "ESM syntax in a file loaded as CommonJS" warning, and every app test still runs.
- Phase: 1 · Planned by: planner · Date: 2026-10-24 · Status: planned

## 1. What to build

Cause (planner probe P1, 2026-10-24, section 2): `app/package.json` and the root `package.json` have no `"type"`, so Vite loads `app/vitest.config.ts`, `app/test-harness/net-guard/probe.vitest.config.ts` and the root `vitest.config.ts` as CommonJS, and each `import` line at 4:1 (3:1 / 5:1) triggers the warning. All three print it (P1: `app/` run, root run, probe run). Fix: rename the three files to `.mts` (Vite loads `.mts` as ESM). Rejected: `"type": "module"` in `app/package.json`, because `app/next.config.ts:6` and `app/src/server/db/seed.test.ts:68` use `__dirname` and Playwright would switch every spec and harness file to ESM loading (lesson L-017 notes in `app/e2e/*.spec.ts`); setting `VITE_CONFIG_NATIVE_IGNORE_WARNING` or `--configLoader` silences instead of removing the cause (ticket row: "the warning is never silenced").

Who writes what: the three config files, every test file and `app/test-harness/**` are test files under `.claude/hooks/guard-paths.mjs` `isTest` (lines 15-17: `__tests__/`, `test-harness/`, `(vitest|playwright)(.config)?.[cm]?[jt]s`), so the test-author writes steps 1-8; the builder writes steps 9-10. After the test-author's steps T1-T5 and T7 pass; T6 fails until step 9.
