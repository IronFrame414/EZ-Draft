- **ACs:** AC-EZD-146-1, AC-EZD-146-2

- **User-visible result:** the dev migrations workflow no longer puts the dev database password on a command line, and a test now proves on the local database that the real Supabase CLI reads the password from `PGPASSWORD` and applies the release's lock and statement timeouts.
- Phase: 1 · Planned by: planner · Date: 2026-10-24 · Status: questions
