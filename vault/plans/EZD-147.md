| rule (j) | SHA pins | Over each line whose trimmed text does not start with `#`, each match of `/(^\|[\s{,])["']?uses["']?\s*:/g`: value = the text after that colon, `stripComment` applied, cut at the first `,` or `}`, trimmed, `stripQuotes` applied. Problem when the value is empty or does not match `PIN_RE` = `/^[A-Za-z0-9_.-]+\/[A-Za-z0-9_.-]+(\/[A-Za-z0-9_.\/-]+)?@[0-9a-f]{40}$/`. `PIN_RE` is the only test: a block-scalar indicator (`>-`, `\|`), an alias (`*x`), an expression, a local path (`./…`), `docker://…`, a tag, a branch, a short, long or upper-case SHA all fail it and are each one problem. A job-level `uses:` (reusable workflow) is scanned the same way |
| rule (k) | permissions | `PERM_RE` = `/^(\s*)["']?permissions["']?\s*:(.*)$/` on lines not starting (trimmed) with `#`. Form, for every match: rest = `stripComment(m[2]).trim()`; `{}` passes; empty rest is a block whose `children()` must be at least one, each matching `/^\s*["']?[a-z-]+["']?\s*:\s*["']?(read\|write\|none)["']?\s*$/` after `stripComment`; any other rest is a problem. Coverage: passes when a match has indent 0; else find the line matching `/^["']?jobs["']?\s*:(.*)$/`: missing, or its `stripComment` rest not empty (flow form `jobs: { … }`), is one problem (`jobs not in block form`; flow jobs are not parsed); and each job (children of `jobs:` at their first indent) must have a direct child (the job's first child indent) matching `PERM_RE`, else one problem naming the job |
