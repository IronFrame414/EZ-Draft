# EZD-176 · Fix: release, backup and dev-migration workflows leave the Node 20 action pins

- **ACs:** AC-EZD-176-1, AC-EZD-176-2

- **User-visible result:** the production release, the two off-site backup runs and the dev-database migration run use the Node 24 versions of GitHub's checkout and setup-node actions, so they no longer carry the "Node.js 20 is deprecated" warning or depend on a runtime GitHub removed on 2026-09-23.

Pin lines (section 3 P1, P2) and the added line (P3) are exact text; indentation is the file's current indentation of the line replaced (6 spaces before `- uses:`, 10 spaces before `with:` children).
