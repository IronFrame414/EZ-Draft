# EZD-273 · Fix: the gate fails when the launcher or ledger gains a stop path that is not on the KEEP list

- **ACs:** AC-EZD-273-1, AC-EZD-273-2, AC-EZD-273-3
- **Complexity:** high (section 8)
- **Areas:** tooling, scripts, process, testing
- **User-visible result:** a change that adds a new way for the launcher to stop, wait or set a ticket aside fails the gate unless it is one of Josh's KEEP stops, so the "build never stops" rule can no longer drift out of the code.
- Phase: 1 · Planned by: planner · Date: 2026-10-29 · Status: questions
