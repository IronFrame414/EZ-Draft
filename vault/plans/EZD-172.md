# EZD-172 · Parallel lanes: each build lane gets its own local database and ports

- **ACs:** AC-EZD-172-1, AC-EZD-172-2, AC-EZD-172-3
- **Complexity:** medium (section 8)
- **User-visible result:** up to three builds can run their full checks at the same time, each on its own local database and ports, without wiping each other's data; a build with no lane set runs exactly as before.
- Phase: 1 · Planned by: planner · Date: 2026-10-24 · Status: planned
