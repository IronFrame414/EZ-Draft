# EZD-174 · Parallel lanes: the launcher runs several units at once when lanes are on

- **ACs:** AC-EZD-174-1, AC-EZD-174-2, AC-EZD-174-3
- **Complexity:** high (section 8)
- **Areas:** tooling, scripts, process
- **User-visible result:** with lanes on, the launcher keeps several plans and builds running (each build on its own local database), runs questions, plan review, phase gate, wrap and repair only when nothing else runs, and stops starting units in every lane during a five-hour pause; with lanes off it runs one unit at a time as before.
