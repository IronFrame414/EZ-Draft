# EZD-174 · Parallel lanes: the launcher runs several units at once under boost

- **ACs:** AC-EZD-174-1, AC-EZD-174-2, AC-EZD-174-3

- **User-visible result:** with boost on, the launcher keeps up to 6 units running (at most 3 builds, each on its own local database), runs questions, plan review, phase gate and wrap only when nothing else runs, and stops starting units in every lane during a five-hour pause; with boost off it runs one unit at a time as before.
