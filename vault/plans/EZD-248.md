**1a. `nextQuestionId()`** reads the three Q_FILES fresh at each call (`read()`), takes the highest number over every line matching `/^\|\s*Q-(\d{4})\s*\|/gm` anywhere in each file (a stray row's ID counts too; NT line 227 "IDs are never reused"), returns `Q-` + `String(max + 1).padStart(4, '0')`, and `Q-0001` when no row exists.

**1b. `questionProblems()`.** Per kind in Q_FILES order (open, answered, archive), with `H = questionHeader(kind)`, `HEAD = H[H.length - 2]`, `SEP = H[H.length - 1]`, `PREFIX = H.slice(0, -2)`, `lines = text.split(/\r?\n/)`:
1. File absent (`existsSync` false): M1; next file.
2. `h = lines.indexOf(HEAD)`; when `h < 0` or `lines[h + 1] !== SEP`: M2, then only steps 6 and 7 for every Q_ROW line of the file.
3. Compare `lines.slice(0, h)` with PREFIX line by line; at the first index `i` where they differ (a length difference counts at the shorter length): M3 with line `i + 1`. Only the first difference is reported.
4. `end` = first index at or after `h + 2` whose line does not match Q_ROW (a blank line ends the table, as in Markdown; the live files have none inside, planner probe). Every Q_ROW line at index `j` outside `h + 2 … end - 1`: M4 with line `j + 1`.
5. Every line at index `j >= end` that is non-blank and not Q_ROW: the existing "line in the questions table that is not a Q-ID row" message, text unchanged.
6. Every Q_ROW line, in or out of the table: when `line.trimEnd()` does not end with the pipe character, M6; else `n = questionCells(line).length - 2`, and `n !== 8` gives M5.
7. The duplicate and status checks run on every Q_ROW line, as now; their messages are unchanged.
Order within a file: steps 1 to 5, then per Q_ROW line in file order M6 or M5, duplicate, status. Tests check presence, never position.
`questionFiles()`, `sortQuestions()`, `questionHeader()` and `questionStatus()` stay as they are.

**1c. `checkStaged({ cwd = process.cwd(), env = process.env } = {})`.** Git runs as `spawnSync('git', args, { cwd, env, encoding: 'utf8', maxBuffer: 64 * 1024 * 1024 })`; env keeps `GIT_INDEX_FILE`, and cwd stays, because that path may be relative (PRB).
1. `git diff --cached --name-only --no-renames -z`; status not 0 gives E1. Names split on NUL; none starting `vault/questions/` returns `{ ok: true, checked: false, output: '' }`.
2. `tmp = mkdtempSync(path.join(tmpdir(), 'ezd-staged-'))`; `git checkout-index --all --force --prefix=<tmp>/`; status not 0 gives E2.
3. `<tmp>/vault/tools/next_ticket.mjs` absent gives E3.
4. `spawnSync(process.execPath, [<that file>, '--check'], { cwd: tmp, env: <env without keys starting GIT_>, encoding: 'utf8', timeout: 120000, maxBuffer: 64 * 1024 * 1024 })`. `status === null` or `error` set gives E4.
