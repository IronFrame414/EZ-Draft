## 1. What to build
Cause (section 2, E1-E4): B4 fails at spec line 200, `await page.goto('about:blank')`, with `Navigation to "about:blank" is interrupted by another navigation to "chrome-error://chromewebdata/"`. Line 199 (the `ezd_signed_out=1` cookie poll) had already passed. The browser carries out the app's `location.replace('/sign-in')` (`app/src/lib/auth/device-sign-out.ts` `signOutOnDevice`) with the network off, so that navigation fails and Chrome then loads its error page. The poll can pass as soon as the `/sign-in` request is sent, before the error page loads. On the CI runner the error page loaded after `page.goto('about:blank')` had started, which interrupted it. **This is a race in the test, not an app bug.** The fix: register a waiter for the error page before "Sign out anyway" is clicked, and wait for it before `about:blank`. B5 runs the same lines (219-227) and gets the same fix. Test file only; no app file changes.
