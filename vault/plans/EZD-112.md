## 1. What to build
IDs: S15a = `vault/spec/sections/screens/S15a-settings-company.md`; B15a = board `vault/mockups/S15aCompany.png` + `.dc.html`; P10x = `vault/plans/EZD-10x.md` section 3; P132 = `vault/plans/EZD-132.md` section 3 and Build steps 4, 7–10 (Q-0266 (b)); ARCH = `docs/architecture.md`.

Data (S15a Controls; 03c tenant; ARCH Row-level security "Grants", "Function grants convention"): no new table or column; `tenant` stays `select`-only; the one write path is this function. No money.

```sql
-- confirm on pinned version (L-009): run once on the local stack before the tests are committed
create function public.update_tenant_identity(
  p_name text, p_license_no text, p_contact jsonb, p_set_logo boolean, p_logo_path text)
returns table (tenant_id uuid, tenant_name text, tenant_logo_path text, tenant_license_no text,
               tenant_contact jsonb, tenant_updated_at timestamptz, changed text[])
language plpgsql volatile security definer set search_path = '' as $$ … $$;
revoke all on function public.update_tenant_identity(text, text, jsonb, boolean, text) from public, anon, service_role;
grant execute on function public.update_tenant_identity(text, text, jsonb, boolean, text) to authenticated;
```
Body in order: (1) `v_tenant := private.tenant_id()`, `v_membership := nullif(auth.jwt() ->> 'membership_id', '')::uuid`; either null → raise `permission_denied` errcode `42501`. (2) No row in `public.user_permission` with that `membership_id`, `tenant_id = v_tenant`, `permission_key = 'settings_company'`, `granted` → `42501` `permission_denied` (backstop behind the route's `can()`; columns `tenant_id, membership_id, permission_key, granted` from the P102 `setPermissions` harness row). (3) `p_name` null or `length(btrim(p_name)) = 0` → `22023` `company_name_required`. (4) `p_contact` null or `jsonb_typeof(p_contact) <> 'object'` → `22023` `invalid_input`. (5) `p_set_logo` and `p_logo_path` not null and not matching `'^' || v_tenant::text || '/tenant/logo/[0-9a-f-]{36}\.(png|jpg|svg)$'` → `22023` `logo_path_invalid`. (6) `select … from public.tenant t where t.id = v_tenant for update`; new logo = `p_logo_path` when `p_set_logo`, else the old value. (7) `changed` = the names of `name`, `logo`, `license_no`, `contact` (that order) whose old value `is distinct from` the new. (8) When `changed` is not empty, one `update public.tenant t set name, logo_path, license_no, contact where t.id = v_tenant` (the `updated_at` trigger stays). (9) Return one row from `public.tenant t where t.id = v_tenant` with `changed`. Qualify every column with `t.`. Pattern: `supabase/migrations/20261020104858_create_link_app_user.sql`.
