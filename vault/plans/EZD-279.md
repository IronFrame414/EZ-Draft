**Helpers (module-private, in secret-paths.mjs).**
- `fold(p)` = `pathKey(norm(p), true)`.
- `realOr(p)` = `try { return norm(realpathSync.native(p)); } catch { return norm(p); }`.
- `targets(given, cwd, home)`: `g = norm(given)`. If `g === '~'`, `g = home`. If `g` starts with `~/`, `g = home + g.slice(1)`. `lexical = norm(path.resolve(norm(cwd), g))`. `raw = path.isAbsolute(g) ? g : norm(cwd) + '/' + g`; the raw join is not normalized, so the OS resolves `..` after links. `real` = `norm(realpathSync.native(raw))`, or `null` when that throws. Returns `[lexical]`, plus `real` when `real !== null && real !== lexical`.
- `under(dir, target)` (dir is target or an ancestor of it): `a = fold(dir).replace(/\/+$/, '')`, `t = fold(target)`. Return `a === '' || t === a || t.startsWith(a + '/')`.
- `lastSeg(p)` = `fold(p).split('/').filter(Boolean).at(-1) ?? ''`.
- `pieces(s)`: walk the characters with `depth` (+1 on `{`, -1 on `}`, never below 0). Split at every whitespace character and at every `,` when `depth === 0`, and drop empty pieces. A `,` inside braces never splits.
- `kindText` = `{ env: 'a .env file', launcher: 'scripts/launcher.config.json', signin: 'the Claude sign-in file' }`.
- `mainRoot(rr)` (the main checkout; ticket worktrees sit under it at `<main>/.claude/worktrees/<T>`, EZD-250 D1a, `.gitignore` line 10): `rr === null` → `null`. Else `m = /^(.+)\/\.claude\/worktrees\/[^/]+$/i.exec(rr)`; return `m ? m[1] : rr`. `rr` is EZD-260 `repoRoot()`, so a worktree project dir and the main project dir give the same `main`.

**S `secretName(abs)`**: `segs = fold(abs).split('/').filter(Boolean)`, `b = segs.at(-1) ?? ''`, `p = segs.at(-2) ?? ''`. Check in this order:
- **S1** `b === '.env' \|\| (b.startsWith('.env.') && b !== '.env.example')` → `'env'`.
- **S2** `p === 'scripts' && b === 'launcher.config.json'` → `'launcher'`.
- **S3** `b === '.credentials.json' \|\| (p === '.claude' && b.startsWith('.cred'))` → `'signin'`.
- Otherwise `null`.

**P `globReach(root, glob, ctx)`** (pure: no file system access):
- **P1** `g = glob.trim()` (no `norm`: a `\` must reach P4). If `g === ''` or `g` starts with `!`, return `null`.
- **P2** `alts = braces(g)` (as typed, never folded: folding a class range shrinks it, `[F-n]` → `[f-n]` loses `e`). `braces` expands the first `{`…`}` group at depth 0: it splits the group's content at depth-0 commas (a group with no comma gives its content), builds prefix + each alternative + suffix, and expands each result again. An unmatched `{` or `}`, or more than 64 results, makes `globReach` return `'unreadable'`.
- **P3** For each `a` of `alts`, in order: if `ctx.tool === 'Grep'`, strip leading `/`s and set `base = root`. Otherwise `base = a.startsWith('/') ? '/' : root`. Then `segs = a.split('/')`, `F = segs.at(-1)`, `D = segs.slice(0, -1).filter((s) => s !== '')`. `lit` = the leading entries of `D` before the first entry that holds any of `* ? [ ] { } !`. `dir = norm(path.posix.resolve(base, ...lit))`. `deep = ctx.tool === 'Grep' \|\| D.some((s) => /[*?[\]{}!]/.test(s))`. If `F === ''` or `F === '**'`, set `F = '*'`.
- **P4** Return `'unreadable'` when any part of `a` (each entry of `D`, and `F`) contains `\`, or any of `@(`, `!(`, `+(`, `*(`, `?(`, or a `[` that has no closing `]` under P5. A folder part is checked too, because ripgrep reads `sc\ripts` as `scripts`.
- **P5** `T = compile(F)`, from `F` as typed. Tokens: a run of `*` → `{ star: true }`; `?` → `{ src: '[^/]' }`; `[` opens a class → `{ src: <class> }`; any other character → `{ src: <escaped>, lit: true }` (`/[.*+?^${}()\|[\]\\]/g` → `\\$&`). Class: a leading `!` or `^` becomes `^`, and a `]` directly after `[`, `[!` or `[^` is a literal; the class ends at the next `]`; inside it `-` between two characters stays a range, `\`, `[`, `]` and `^` are escaped with `\`, every other character is copied as is. Every non-star token keeps two RegExps: `cs = new RegExp('^(?:' + src + ')$', 'u')` (case-sensitive, as ripgrep) and `ci = new RegExp('^(?:' + src + ')$', 'iu')` (Unicode simple case folding: `ſ` matches `s`, as `pathKey` folds). `accept(tok, c)` = `tok.cs.test(c) \|\| tok.cs.test(c.toLowerCase()) \|\| tok.cs.test(c.toUpperCase()) \|\| tok.ci.test(c)`: a token accepts `c` when it accepts any case of it, so a range keeps its typed bounds and a negated class `[!E]` still accepts `e` (security round 2). When any `new RegExp` throws (a reversed range such as `[z-a]`), `compile` returns `null` and `globReach` returns `'unreadable'`. `walk(T, s)`: an exact NFA over the tokens: `S = close({0})`, then for each character `c` of `s`, `S = close({ i : i in S, T[i] is a star, c !== '/' } ∪ { i + 1 : i in S, i < T.length, T[i] not a star, accept(T[i], c) })`; returns `S`. `match(F, name)` = `walk(T, name)` contains `T.length`. No whole-name RegExp is built, so `match` and `prefixHit` agree.
- **P5a** `prefixHit(T, pre, except)`: true when the matcher accepts some name that starts with `pre` (in any case) and, when `except` is given, is not `except` in any case. Exact, by stepping a set `S` of token positions:
  1. `S` = `close({0})`; `close` adds `i + 1` for each `i` in `S` whose token is a star, repeatedly.
  2. For each character `c` of `pre`: `S` = `close({ i : i in S, T[i] is a star } ∪ { i + 1 : i in S, i < T.length, T[i] not a star, accept(T[i], c) })` (the `walk` step). An empty `S` returns false.
  3. Some `i` in `S` with a star in `T.slice(i)` → true (the rest takes names of every length).
  4. For each `i` in `S`, `R = T.slice(i)`: true when `except` is undefined, or `R.length !== except.length - pre.length`, or some `R[j]` is not `lit`, or `!accept(R[j], except[pre.length + j])`.
  5. Otherwise false. A class or `?` in step 4 counts as able to match another name (fail closed; it can only refuse more, such as `.env.[e]xample`).
- **P6** `at(target)` = `deep ? under(dir, target) : fold(dir) === fold(target)`. Folder and dir compares stay folded.
  - `'env'` when `match(F, '.env') \|\| prefixHit(T, '.env.', '.env.example')`. This applies in any folder.
  - `'launcher'` when `match(F, 'launcher.config.json') && ((ctx.repoRoot !== null && at(ctx.repoRoot + '/scripts')) \|\| lastSeg(dir) === 'scripts')`.
  - `'signin'` when `(match(F, '.credentials.json') \|\| prefixHit(T, '.cred')) && (at(ctx.home + '/.claude') \|\| lastSeg(dir) === '.claude')`.
  - Check the kinds in that order. The first alternative that gives a kind or `'unreadable'` returns it.
- **P7** No alternative gives a kind → `null`.

**H `secretReason(tool, ti, cwd)`**: `home = realOr(os.homedir())`, `rr = repoRoot()`, `str(v) = typeof v === 'string' && v !== '' ? v : null`. A field that is not a string is treated as absent.
- **H1 Read**: `f = str(ti.file_path)`. If `f` is `null`, return `null`. For each `t` of `targets(f, cwd, home)`: when `k = secretName(t)` is not null, return W1(`f`, `k`).
- **H2 Grep**: `p = str(ti.path)`. `bases = p ? targets(p, cwd, home) : [...new Set([norm(cwd), realOr(cwd)])]`. Check in this order, returning the first hit:
  1. For each `t` of `bases`: if `secretName(t)` gives `k`, return W2('Grep', `k`).
  2. For each `t`: if `under(t, home + '/.claude')`, return W2('Grep', 'signin').
  3. `main = mainRoot(rr)`. When `main === null` or `!under(main, bases.at(-1))`, return W5(`p ?? norm(cwd)`). `bases.at(-1)` is the real path when it exists (`targets` order), else the lexical one, so a link inside the repo to an outside folder is refused and a link from outside into the repo is allowed (Q-0462 (a)).
  4. When `str(ti.glob)` is set, for each piece `q` of `pieces(ti.glob)` and each `t`: `r = globReach(t, q, { tool: 'Grep', home, repoRoot: rr })`. `'unreadable'` → W3('Grep', `q`); a kind → W2('Grep', `r`).
- **H3 Glob**: `p` and `bases` as in H2. Check in this order:
  1. `secretName(t)` gives `k` → W2('Glob', `k`).
  2. `pat = str(ti.pattern)`. If `pat` is `null`, return `null`. For each piece `q` of `pieces(pat)` and each `t`: `globReach(t, q, { tool: 'Glob', home, repoRoot: rr })` → W3 or W2 as in H2.
- **H4** Any other tool, or no hit → `null`.
