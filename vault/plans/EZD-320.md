# EZD-320 · Fix: a project member cannot complete or orphan another person's pending source-file upload

- **ACs:** AC-EZD-320-1, AC-EZD-320-2
- **Complexity:** high
- **Areas:** migrations, security, data-model, testing
- **User-visible result:** only the person who started a file upload can finish it, and nobody can erase who uploaded a file; removing a user still works.
- Phase: 1 · Planned by: planner · Date: 2026-11-03 · Status: planned

Data: no new table, column or money field; `schema_version` unchanged. One forward-only migration replaces policy `source_file_update` and function `private.source_file_keep_original()`; the released migration is not edited (ticket row). Grants unchanged (TABLE_GRANTS, EZD-132 section 3).
