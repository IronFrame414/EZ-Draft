| D15 Store | **Version rule (the one stale-page guard):** a private integer `version` goes up by one at exactly three points: a first page applying, every `reset()` call, every `applyRead()` call (also when nothing changes; ok `markAllRead`/`open` change state only through it). A fetch records `version` when it starts; if it moved by the time the fetch settles, the fetch changes nothing on success or failure (every field and flag stays): a stale first page only sets `wanted`, so the run's loop fetches once more (no inner retry); a stale older fetch is dropped. A bump while `olderStatus` is `'loading'` sets it `'idle'` in the same change (Show older shows again). **Run:** `refresh()` sets a private `wanted` flag, starts the run if none is running and returns the running run's promise. The run loops while `wanted`: clear it, record `version`, fetch the first page, apply per the rule; it clears its running handle in the same synchronous step as its last `wanted` check (not in `.finally`). Many `refresh()` calls during a fetch cost one more fetch. **A first page applies:** it MERGES only when no replace is pending, an older page is loaded, `page.hasMore` is true and the page's last id is among the loaded items: `items` = the page's items, then the loaded items after that id (in order, ids in the page skipped), `unreadCount` = the page's, `hasMore` unchanged, `olderStatus` per the bump rule. Every other first page REPLACES: `items`, `hasMore`, `unreadCount` = the page's, `olderStatus` `'idle'`, older pages forgotten, pending replace cleared (a `hasMore` false page is the whole list; one not reaching the loaded items would leave a gap). **`reset()`** (resync) bumps, keeps the shown state in every `status` (items, count, dot; Q-0549 (b)), marks a replace pending until a first page applies, then `refresh()`. **`loadOlder()`**: cursor = last item; no bump; success appends unseen ids, sets `hasMore`, `unreadCount` = the page's, `olderStatus` `'idle'`, older page loaded. `applyRead(id)`: a loaded item with that id and `readAt` null gets `readAt` = `new Date().toISOString()` and `unreadCount` − 1 (not below 0); not loaded or already read → no state change (D16's following `refresh()` brings the server count). `applyRead(null)`: every loaded item with `readAt` null gets it set the same way; `unreadCount` 0 (null is sent only by mark-all, M3). `open(id)`: ok → exactly `applyRead(id)`, return the result; not ok → `await refresh()`, then return the result (D17's toast follows the refetch); `api.open` rejecting counts as `{ ok: false, messageKey: 'error.db_unavailable' }`. `markAllRead()`: ok → exactly `applyRead(null)`, `true`; failure → state unchanged, `false`.
