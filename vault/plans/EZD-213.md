# EZD-213 · Inspector fields (split proposal)

- **ACs:** AC-EZD-213-1 … AC-EZD-213-24 (`vault/spec/acceptance-criteria.md:920-943`, stage-0), shared out to the parts below (each AC in one part; AC-20 and AC-23 split by clause, AC map; AC-20's delete clause is proved by EZD-217 C4 (c), Q-0644 (b))
- **Complexity:** high (parts a and b), medium (part c); reasons per part
- **Areas:** ui, testing, data-model
- **User-visible result:** Selecting a wall, door or window opens the 336 px inspector on the right with its number, where it is, and its fields. Josh types a wall's length, thickness or height, edits its layers, ticks Bearing, and sets a door's size, swing and hand, offset, rough opening and impact rating; with several walls selected one typed thickness changes them all and differing values read "Mixed". A room's closure gap is resolved from the inspector. View-only users read the same panel as plain text.
- Phase: 5 · Planned by: planner · Date: 2026-11-08 · Status: split proposal

## Split proposal

**Why.** Planned whole, the ticket touches about 40 files and needs about 55 tests. That is over the size rule (PROCESS.md section 6 "Ticket size": about 20 files or 25 tests; Josh 2026-10-22). Where the count comes from:
- 24 stage-0 ACs. Eight of them carry several numeric cases: 09j Typed lengths rows 10, 12, 13, 15, 16; 09k Typed length, Thickness ×4, Partition 6 1/2"; Q-0640's layer examples; and AC-22's left, right and vertical cases.
- Model edits for every field: wall length (end moves, start stays, joined walls follow: 09-calc Q-0630 row 12); thickness through the stud layer (row 13); layer rows (Q-0635, Q-0640); height; bearing (03f; 05 Q-0630 row 15); opening size with the rough opening following while auto (09-calc Q-0630 sizes; Q-0633 G11); typed rough opening (Q-0640 row 5-5); offset (`placeAtOffset`, P204 section 3); sill; impact and shutter type (Q-0633 G11); swing and hand (03 Q-0630 row 4). Each change goes through `wallEditChanges(objects, level, walls, newId, highs)` (P294 section 3) so rooms reconcile, and each commit is one `applyEdit` = one undo step (`app/src/editor/model/model-store.ts`; 04 Q-0630 row 20; Q-0640 row 5-4).
- Pure view rules: titles with object numbers (Q-0511 (b); Q-0633 G14; S03d W14), the sub-line (W1: rooms on each side, host wall number), Offset left and the corner caption (W5; Q-0640 row 5-1; Q-0641 row 1), the Hinge left/top labels (W8; Q-0642 row 3; P204 `leftEndIsLow`, `isVerticalLine`), the swing labels and result line (W9, W10), and shared fields with Mixed (04 Left panel and inspector; S03 Bulk edit).
- A new screen region. The `inspector` aside of `EditorFrame` gets its first content (`app/src/components/shell/EditorFrame.tsx:61`; ARCH Editor shell: 336 px). It holds the empty state (W15, W16; T6 on a tablet: Q-0633 G9), the single wall and single opening panels (boards S03dWallSelected, S03dDoorSelected, S03dWindowSelected), bulk edit (S03dStates), view-only plain text with the W17 badge (05 Q-0630 row 9), the Not on a wall block (W13; 04 Q-0630 row 27), Edit layers (Q-0635), the double-click that focuses Length (Q-0630 row 33; P208 D4 leaves it to this ticket), en and es catalog keys, and browser tests for Josh's Slice 5 script steps 2 and 5.
- The closure gap's panel moves from the box near the gap (`app/src/editor/tools/GapBoxes.tsx`, `DrawingTools.tsx:106`) into an inspector section (Q-0569; S02 board "Resolve the gap"; 05 Q-0630 row 24).

**Why cut here.**
- The three dependencies are not built (`vault/tickets/STATUS.md`, read 2026-11-08: EZD-204 and EZD-208 `planned` as split proposals, EZD-294 `in-progress`). Part a needs only their contracts: P204 section 3 (hinge-label helpers, `openingOffsets`, `placeAtOffset`, `openingHostUpdates`), P294 section 3 (`objectNumber`, `wallEditChanges` with `highs`) and P212 part a (wall-end and opening-width resize). Parts b and c also need EZD-208's selection (P208 section 3: `getUi().ids`, `subscribe`, `select(ids)`, `SelectionLayer`).
- Part a is pure TypeScript with unit tests only. Geometry goes in `packages/geometry` (ARCH Folder layout: "pure TypeScript, no UI"). The inspector's view and change rules go in `app/src/editor/inspector/`. This is the same cut as EZD-212a and EZD-209/EZD-210 (pure module first, then the screen).
- Part c is cut out because it changes the gap box that EZD-212b also changes (P212 part b: `office.tools.gap.fix_later` and the edits `gap.test.ts:102`, `GapBoxes.test.tsx:82`; 05 Q-0630 row 23). It is built after EZD-212b so the two changes do not collide.

Built a → b → c. Each part is planned as its own unit from its section here. Each part plan applies the planner lessons for ui, testing and data-model. Most apply to UI and test work: the inventory tests that pin lists (L-021: `HeaderButton.icon.test.tsx` if an icon is added; `EmptyEditor.test.tsx:46-57` for the inspector region); empty, maximum and malformed cases for every typed field (L-052); 44 px touch targets for every new control (L-060); measured checklist rows (L-054); a fixture source file and an e2e project or tag for every test row (L-064); and model fixtures built from the geometry package defaults (EZD-120d line in planner lessons).

### Part EZD-213a · Inspector edits and view rules
- **Scope:** pure functions, no DOM and no React:

    - bearing set and clear (03f; `attributes.bearing` in `G/schema/wall.ts`);
    - opening size: width and height above 0" (row 14). An `auto` rough opening follows the size by `autoRoughOpening` (P204 step 4). A typed rough opening sets `roughOpeningMode 'typed'` (Q-0633 G11; Q-0640 row 5-2);
    - sill at 0" or more (row 14);
    - impact rating, plus a shutter type only with `shutter` (Q-0633 G11; P204 Decided "Opening v4" rule (b));

    - **change builders.** One field commit over the whole selection gives one `Change[]` through `wallEditChanges` (rooms reconcile; P204 appends host updates). It is committed by one `applyEdit`, so it is one undo step, and a bulk edit is also one step (04 Q-0630 row 20).
    - **view rules.** Title "Wall n" / "Door n" / "Window n" from `objectNumber` (Q-0511 (b); Q-0633 G14), and the W14 bulk titles and subtitle. For several walls, board S03dStates gives Thickness, Height, Layers and Bearing, with no Length and no Status. Mixed types follow Q-0645 (a).
