**R1 `cacheUses(lines)`** (rule (i), run by `checkWorkflow` for `release.yml`, `backup-files.yml`, `backup-db.yml` only, unchanged). For each line `l` at index `i` whose trimmed text does not start with `#`, with `n = i + 1`, `t = l.trim()`, `body = stripComment(l)`, push in this order:
1. `explicit key at line n` when `t` matches `/^(-\s+)?\?(\s|$)/`.
2. `escaped key at line n` when `body` matches `/"[^"]*\\[^"]*"\s*:/`.
3. For each match of `USES_KEY_RE` = `/(^|[\s{,])["']?uses["']?\s*:/gi` in `body`: `raw` = the text after the match, cut at the first `,` or `}`, trimmed. `raw` empty or starting with one of `> | * & !` → `unreadable uses value at line n`. Else `value` = `raw` with one leading `"`/`'` and one trailing `"`/`'` removed, trimmed, lower-cased; `value` matches `/^actions\/cache(\/|@|$)/` → `` `${value} at line n` ``.
4. `cache key at line n` when `body` matches `CACHE_KEY_RE` = `/(^|[\s{,?])["']?cache["']?\s*:/i` (any step, any depth, block or flow).
5. `PM_CACHE_RE` = `/(^|[\s{,?])["']?package-manager-cache["']?\s*:\s*("[^"]*"|'[^']*'|[^\s,}#]*)/i`; on a match, `stripQuotes(m[2]).toLowerCase() !== 'false'` → `package-manager-cache at line n`.
The setup-node step walk of the old body is deleted (item 4 covers every step). The cut at `,` or `}` only shortens the tail of a value, so it never hides an `actions/cache` prefix; no sample for a comma inside a quoted value.

**R2 `buildSettingProblems(text)`**. `stripYamlComment(s)` = `s.replace(/\s+#.*$/, '')`. `KEY(name)` = `new RegExp('(^|[\\s{,?])["\']?' + name + '["\']?\\s*:', 'i')`. Lines = `text.split(/\r?\n/)`. For each line `l` (index `i`) not blank and whose trimmed text does not start with `#`, with `body = stripYamlComment(l)`:
- `unreadable` when the trimmed text matches `/^(-\s+)?\?(\s|$)/`, or `body` matches `/"[^"]*\\[^"]*"\s*:/`;
- `permissions` when `KEY('permissions')` matches `body`;
- `allow-all` when `KEY('dangerouslyAllowAllBuilds')` matches `body` (any value);
- remember `i` when `KEY('allowBuilds')` matches `body`.
Then: more than one remembered line → `allowBuilds-form` (`allowBuilds appears more than once`). With at least one: `body` of the first remembered line `!== 'allowBuilds:'` (checked after `trimEnd()`) → `allowBuilds-form` (`allowBuilds must be a top-level block map`), and no entry check; otherwise walk the following lines exactly as EZD-001 T10 does now (skip blank and `#` lines, stop at the first line not starting with whitespace): a line matching `/^\s*-\s/` → `allowBuilds-form`; a line not matching `/^\s+(['"]?)([^'":]+)\1:\s*(.+?)\s*$/` → `allowBuilds-entry`; `m[3] !== 'false'` → `allowBuilds-entry`. No `allowBuilds` line → no allowBuilds problem (T10 behavior kept). Each `msg` names the line number.

**R3 `checkAllowBuilds(text)`** (the module-level function declaration of that name in `workflow.test.mjs`; T17's needle loop checks only `dangerouslyAllowAllBuilds` and `onlyBuiltDependencies`, so nothing there refuses `permissions` today): before its `return`, push `'permissions setting'` when any line whose trimmed text does not start with `#` has, after `.replace(/\s+#.*$/, '')`, a match of `/(^|[\s{,?])["']?permissions["']?\s*:/i`. Everything else unchanged.
