- **M1** `supabase/migrations/<ts>_widen_job_kind_notification_email.sql` (D28): `alter table public.job drop constraint job_kind_check, add constraint job_kind_check check (kind in ('import','export','render','ai_read','thumbnail','diff','cleanup','test','notification_email'));` (constraint name read on the pinned stack 2026-10-29; widening passes Release safety; EZD-009 T20 then expects `JOB_KINDS`).
- **M2** `<ts>_create_notification.sql`, run on the pinned stack 2026-10-29 (L-009):
  - `public.notification`: `id uuid pk default gen_random_uuid()`, `tenant_id uuid not null references public.tenant (id) on delete cascade`, `user_id uuid not null references public.app_user (id) on delete cascade`, `kind text not null check (kind in (<NOTIFICATION_KINDS, same order>))`, `project_id uuid` (**no foreign key**: AC-7 needs the id after the project is deleted; D3), `payload jsonb not null default '{}'::jsonb check (jsonb_typeof(payload) = 'object' and octet_length(payload::text) <= 4096)`, `link text not null check (length(link) <= 2048 and link ~ '^/([^/\\].*)?$' and link !~ '[[:cntrl:][:space:]]')`, `read_at timestamptz`, `emailed_at timestamptz`, `created_at timestamptz not null default now()`, and `constraint notification_params_check check (case kind when 'edit_request' then coalesce(jsonb_typeof(payload -> 'name') = 'string', false) when 'client_response' then coalesce(payload ->> 'action' in ('approved','commented'), false) and coalesce(jsonb_typeof(payload -> 'version') = 'string', false) else true end)`.
  - Indexes `notification_tenant_id_idx (tenant_id)`, `notification_project_id_idx (project_id)`, `notification_user_list_idx (user_id, created_at desc, id desc)`, `notification_user_unread_idx (user_id) where read_at is null`.
  - RLS on; `notification_select` for select to authenticated using `tenant_id = (select private.tenant_id()) and user_id = (select private.app_user_id()) and (project_id is null or (select private.all_projects()) or project_id = any ((select private.listed_project_ids())::uuid[]))`; restrictive `notification_api_gate` (ARCH RLS template). No insert/update/delete policy.
  - `grant select on public.notification to authenticated; grant select, insert, update, delete on public.notification to service_role;`
  - Trigger `notification_broadcast_created` after insert for each row → `private.notification_broadcast_created()` (plpgsql, security definer, `search_path = ''`): `perform private.broadcast_user(new.user_id, 'notification.created', jsonb_build_object('notificationId', new.id))` inside `begin … exception when others then raise warning 'notification_broadcast_failed'; end;`, `return null`; `revoke all on function … from public` (L-016). `realtime.send` adds `id` to the payload; `toEventPayload` drops it (EZD-018 lesson).
- **M3** `<ts>_create_notification_functions.sql` (bodies compiled on the pinned stack 2026-10-29; each `public` definer function starts `perform private.require_api_gate();` (EZD-190) and reads `v_tenant := private.tenant_id(); v_user := private.app_user_id();`, raising `42501 not_authorized` when either is null):
  - `private.create_notification(p_tenant_id uuid, p_user_id uuid, p_kind text, p_project_id uuid, p_payload jsonb, p_link text) returns uuid`, plpgsql volatile security definer. Any null except `p_project_id` → `raise 22023 invalid_notification`. Returns **null** (inserts nothing) when the user has no `active` membership in the tenant, the project is not in the tenant, or the membership is `listed` without that project. Otherwise inserts the row, then `insert into public.job (tenant_id, project_id, kind, payload, status, max_attempts, run_after) values (p_tenant_id, null, 'notification_email', jsonb_build_object('notificationId', v_id), 'queued', 5, now())`; returns the id. Revoke from public; no grant (later kinds call it from triggers).
  - `public.send_test_notification(p_kind text, p_project_id uuid, p_payload jsonb) returns uuid`, definer: project given and `not coalesce(private.can_see_project(p_project_id), false)` → `42501`; `v_id := private.create_notification(v_tenant, v_user, p_kind, p_project_id, coalesce(p_payload, '{}'), '/')`; null → `42501`.
  - `public.list_notifications(p_before_created_at timestamptz, p_before_id uuid) returns jsonb`, **sql stable security invoker** (RLS limits rows to the caller): page = rows where `p_before_created_at is null or (created_at, id) < (p_before_created_at, p_before_id)` ordered `created_at desc, id desc` limit 21; returns `{ items: first 20 as { id, kind, params: payload, link, projectId, projectName: project.name, clientName: customer.name, readAt, createdAt }, unreadCount: count(*) where read_at is null, hasMore: page count > 20 }`, left joining `public.project` on `project_id` and `public.customer` on `project.customer_id` (RLS hides projects the caller cannot see, so their names are null).
  - `public.open_notification(p_id uuid) returns table (link text, project_id uuid, project_state text)`, definer: select own row `for update` (`id`, tenant, user, and the scope clause of `notification_select`); none → return no row. If `read_at is null`: set `read_at = now()` and broadcast `notification.read` `{ notificationId: id }` (exception-wrapped). `project_state`: `none` (no project), `gone` (no `project` row in the tenant), else `visible` (the scope clause already passed, so a listed member's unlisted project never reaches this point).
  - `public.mark_all_notifications_read() returns integer`, definer: update own unread rows in scope to `now()`; when the count > 0 broadcast `notification.read` `{ notificationId: null }`; return the count.
  - The four `public` functions: `revoke all … from public, anon, service_role; grant execute … to authenticated;`.
- No money fields. Payload values are strings shown only to the recipient; Realtime payloads carry ids only (ARCH Realtime payload rule).
