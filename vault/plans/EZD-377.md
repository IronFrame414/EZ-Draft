# EZD-377 · Fix: the launcher recognises the documented limit messages and never restarts a unit in a loop

- **ACs:** AC-EZD-377-1 (L1-L7, R1-R4), AC-EZD-377-2 (Q1-Q5), AC-EZD-377-3 (S1-S5)

- **Areas:** tooling, scripts, testing
