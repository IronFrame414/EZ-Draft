| # | Choice | Decision | Source |

| D1 | How the connection reaches psql | Environment variables of the psql child only; no `--dbname`, no positional database argument, no URL or password in `args`. | phase-00.md row EZD-041 Scope; AC-EZD-041-1 |
| D2 | `PG*` variables vs a password or service file | `PGPASSWORD` in the child env; no `PGSERVICE`, `PGSERVICEFILE` or `PGPASSFILE` is written, so nothing holding the password is written to disk. | phase-00.md row Scope ("through the environment (PGSERVICE/PG* variables)"); architecture `### Environments and releases` Tenant 1 ("nothing is written to disk") |
| D3 | `PSQL_ARGS` value | exactly `['-v', 'ON_ERROR_STOP=1', '-X', '-q', '-t', '-A']`: today's flags (`bootstrap.mjs:7`) minus `--dbname` and the URL, same order. | `scripts/release/bootstrap.mjs:7`; Scope |
| D4 | `pgEnvFromUrl` parsing | `new URL(dbUrl)` on a string. Refuse unless `protocol` is `postgresql:` or `postgres:`. `hostname` must be non-empty and hold no `,`; strip one pair of surrounding `[` `]` (IPv6: `hostname` is `[::1]` with brackets for this scheme, probe below) → `PGHOST`, case kept as written (Node 22.23.3 keeps the case of a `postgresql:` host, planner probe 2026-10-23). `port` non-empty → `PGPORT` (string, as written). `username` non-empty → `PGUSER = decodeURIComponent(username)`. `password` non-empty → `PGPASSWORD = decodeURIComponent(password)`. `pathname` minus its one leading `/`, non-empty → `PGDATABASE = decodeURIComponent(...)`. A non-empty `hash` is refused. Empty parts are omitted (libpq defaults apply), never set to `''`. | R-015 items 1, 7; `scripts/release/context.mjs` `valuesToMask` (decodes the password with `decodeURIComponent`) |
| D5 | Query parameters | Split the raw text after the first `?` on `&`; each pair splits at its first `=`; key and value pass through `decodeURIComponent` only (a `+` stays `+`, matching libpq). Allowed keys and their variables (`PG_QUERY_ENV`): `options` → `PGOPTIONS`, `sslmode` → `PGSSLMODE`, `sslrootcert` → `PGSSLROOTCERT`, `application_name` → `PGAPPNAME`, `connect_timeout` → `PGCONNECT_TIMEOUT`, `target_session_attrs` → `PGTARGETSESSIONATTRS`. Refused: any other key (including `host`, `port`, `dbname`, `user`, `password`, `service`, `passfile`, `hostaddr`), a key given twice, a pair with no `=`, an empty value. An empty query (`?` with nothing, or no `?`) sets nothing. | R-015 item 1; `scripts/release/push.mjs:7-9` (`%20` decoded by libpq, `+` not) |
| D6 | Refusal | Throw `Object.assign(new Error('db_url_invalid'), { code: 'db_url_invalid' })` through the existing `codeError`; no `cause`, never the URL, password or host in the message or any property. Also for a non-string or empty `dbUrl`, a `new URL` failure (a multi-host list throws `ERR_INVALID_URL` on Node 22.23.3; `postgresql:///d` parses with an empty `hostname` and is refused by D4's check; planner probe 2026-10-23) and a `decodeURIComponent` `URIError`. | `bootstrap.mjs` `renderBootstrap` pattern; Q-0112 finding 7 (no derived secret in output) |
| D7 | Child env in `createSql` | `env` = `childEnv(process.env)` read at call time, minus every key whose name starts with `PG` (case-sensitive), then `Object.assign` of `buildPsqlInvocation({ dbUrl }).env`. So no inherited `PG*` variable (`PGSERVICE`, `PGHOSTADDR`, `PGPASSFILE` among them) changes where psql connects. `childEnv` itself is not changed. | `dump.mjs` `childEnv`; R-015 item 1 (env vars apply when not set by the caller) |
