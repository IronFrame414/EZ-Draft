**Step 4, `runTreeCheck(dir, env)`** (not exported; placed directly above `checkStaged`). Moves lines 260–266 of `checkStaged` (child env, spawn, outcomes) into one function, unchanged in behavior: `nt = path.join(dir, 'vault/tools/next_ticket.mjs')`; child env = `env` without every key starting `GIT_`; `spawnSync(process.execPath, [nt, '--check'], { cwd: dir, env, encoding: 'utf8', timeout: 120000, maxBuffer: 64 * 1024 * 1024 })`; `status === null` or `error` → `{ state: 'unfinished', why: r.signal || (r.error && r.error.message) || 'no status' }`; status 0 → `{ state: 'ok' }`; else `out` = trimmed stdout and `first` = the first stdout line starting `- ` without the `- `, else the first non-blank line of stdout then stderr, else `(no output)` → `{ state: 'failed', first, out }`. The existence check of `nt` stays in each caller (their messages differ). `checkStaged` then calls `runTreeCheck(tmp, env)` and builds exactly its current three outcomes and texts; EZD-248 C1–C9 prove it unchanged.

**Step 4, `checkRefUpdate`**, in this order (lesson L-004: no early return skips a later rule):
1. `lines = input.split('\n')`; drop the last element when it is `''`. Each line must match `^([0-9a-f]{40}|[0-9a-f]{64}|ref:\S+) ([0-9a-f]{40}|[0-9a-f]{64}|ref:\S+) (\S+)$` (githooks(5): `<old-value> SP <new-value> SP <ref-name> LF`; ref names hold no space, `git check-ref-format`). The first line that does not → return refusal W3. All lines are read before any is acted on.
2. Targets: lines whose ref name is exactly `refs/heads/develop` (Q-0421 (c)). None → `{ ok: true, checked: false, output: '' }`.
3. For each target, in input order: new value starting `ref:` → return refusal W4.
4. New value all zeros → skip it (deletion; `git pack-refs` deletes the loose develop this way, probe P3).
5. `current` = stdout of `git rev-parse --verify -q refs/heads/develop` (trimmed; `''` on non-zero exit). New value `=== current` → skip (no change; `pack-refs` writes the packed copy of the current value, probe P3; in `prepared` rev-parse reads the old value, probe P4).
6. `git cat-file -t <new>`: non-zero exit → refusal W2 with why `git cat-file failed: <first line>`; output other than `commit` → W2 with why `<new> is not a commit`.
7. Each distinct remaining new value once: `tmp = mkdtempSync(path.join(tmpdir(), 'ezd-ref-'))`; with env `{ ...env, GIT_INDEX_FILE: path.join(tmp, 'index') }` run `git read-tree <new>` then `git checkout-index --all --force --prefix=<tmp>/tree/`; non-zero → W2 with why `git read-tree failed: <first line>` / `git checkout-index failed: <first line>`; no `<tmp>/tree/vault/tools/next_ticket.mjs` → W2 with why `the commit holds no vault/tools/next_ticket.mjs`; then `runTreeCheck(<tmp>/tree, env)`: `unfinished` → W2 with why `the ledger check did not finish (<why>)`; `failed` → refusal W1. `rmSync(tmp, { recursive: true, force: true })` in `finally`.
8. All passed → `{ ok: true, checked: <true when step 7 ran at least once>, output: '' }`.
Every git call: `spawnSync('git', args, { cwd, env, encoding: 'utf8', maxBuffer: 64 * 1024 * 1024 })` (as `checkStaged`); `<first line>` is `firstLine(r)`, moved unchanged from inside `checkStaged` (line 250) to module level above `runTreeCheck`; `checkStaged` calls the moved one. A refusal returns `{ ok: false, checked: <step 7 reached>, output: <W text> }`.

```sh
#!/bin/sh
# EZD-263: an update of develop is refused when the ledger check fails on the commit it would leave.
[ "$1" = prepared ] || exit 0
in=$(cat)
case "$in" in *" refs/heads/develop"*) ;; *) exit 0 ;; esac
printf '%s\n' "$in" | node "$(dirname "$0")/../vault/tools/next_ticket.mjs" --check-ref-update
```
