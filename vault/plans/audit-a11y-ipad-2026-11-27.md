# Accessibility and iPad / touch audit, 2026-11-27

Read from the code only (CSS, components, service worker rules). Nothing was run: no gate, no browser, no device.
Sizes are worked out from the CSS, so each one should be checked on a real iPad before it is fixed. Paths are under
`app/src/`.

Not repeated here, already found by the live audit of 2026-11-24 (`audit/ui-live-2026-11-24/REPORT.md`): F3 Projects on
a phone, F4 edit bar over Zoom in (EZD-1979), F6 version switcher tap area, F8 the 107 small controls in Settings,
Libraries, Sheets and the cabinet library (EZD-1980), F16 no EZ Binder link on the empty field pack. The Plan, 3D,
Measure and Photo tabs of the field pack show an empty panel because EZD-1405, EZD-1406 and EZD-1410 are not built.

What passed: no click handlers on divs or spans anywhere; icon-only buttons have names (one search box does not, A30);
pinch zoom is not blocked; hover-only reveals are inside `(hover: hover)`; field pack and field measure controls are
44 px; most dialogs use Radix (focus trap and return).

Contrast was computed from `styles/tokens.css` against white (`--ez-surface`). AA needs 4.5:1 for text, 3:1 for
control outlines.

| --- | --- | --- | --- |

| `--ez-slate-450` | 4.83 | 4.51 | passes on white, fails on tints (4.3) |

| `--ez-border` (input outlines) | 1.30 | | fails 3:1 |

"Look" column: **Josh** = it changes how something looks or reads, so Josh decides. **Code** = no visible change on
desktop, an agent can fix it.
