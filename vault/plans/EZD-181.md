# EZD-181 · Fix: a health check that times out reports the error

- **ACs:** AC-EZD-181-1
- **Complexity:** low (section 8)
- **User-visible result:** nothing on screen; when the database hangs, `/api/health` still answers its failure at the 3-second limit and Josh gets the error in Sentry (and the new-error email once the database answers again), instead of nothing. This ticket proves it with tests; the code is EZD-169's.
