## 1. What to build

No data, tables or migrations. Three parts: a pure turn-angle module in the geometry package (AC-4), a pure typed-entry reducer plus a React layer in `app/src/editor/typed-entry/` (AC-1, 2, 3, 5), and a stub-tool test page. The layer is not mounted in the real editor: EZD-210 mounts it with the first real tools (Q-0570 "The typed bar shows only with a tool active"; Q-0500 a control appears when its ticket ships; section 9).

### Decided for the builder
| Choice | Decision | Source |
| --- | --- | --- |
| D-Angle parse | `parseTurnAngle(text)`: `s = text.trim()`; `s.length === 0` or `s.length > 16` → refused; `s` must match `/^\d+(?:\.\d+)?$/` else refused; `n = Number(s)`; `n < 180` → `{ ok: true, degrees: n }`, else refused. Refused = `{ ok: false, messageKey: TURN_REFUSED_MESSAGE_KEY }`. No `°`, sign, exponent or leading `.` is accepted. Never throws. | Q-0570 (0 up to but not including 180, decimals as typed; 180, above and negatives refused); 16-char bound: CLAUDE.md rule 18, EZD-201 D2 pattern |
| D-Turn | `resolveTurnDirection({ previous, toCursor, turnDeg })`, `c = toCursor`: (1) `turnDeg === null`: `len = Math.hypot(c.x, c.y)`; `len === 0` → `null`; else `{ x: c.x/len, y: c.y/len }`. (2) else `ref` = `previous` normalized when `previous !== null` and its length > 0; otherwise `{ x: c.x < 0 ? -1 : 1, y: 0 }`. `cross = ref.x*c.y - ref.y*c.x`; `s = cross < 0 ? -1 : 1`; `a = s*turnDeg*Math.PI/180`; return `{ x: ref.x*Math.cos(a) - ref.y*Math.sin(a), y: ref.x*Math.sin(a) + ref.y*Math.cos(a) }`. Works in either y direction: the turn always goes to the cursor's side of `ref`. It does not validate `turnDeg` (callers pass a `parseTurnAngle` result). | Q-0560 (turn from the last wall; cursor side picks left or right; nothing typed → where the cursor points); Q-0570 (first wall from the page's horizontal); 09j Turn angle rows 1–5 |
| Snapping | Not here. `toCursor` is already snapped by the caller (EZD-210 with EZD-206). | Q-0570 ("where the cursor points" means after snapping) |
| D-Fields | `WALL_LENGTH_FIELD` = `{ id: 'length', label: 'office.typed.field.length', kind: 'length', lengthKind: 'wall_room', optional: false }`; `TURN_ANGLE_FIELD` = `{ id: 'angle', label: 'office.typed.field.angle', kind: 'angle', optional: true }`. EZD-210 reuses them. | S03 Tab (Length → Angle); Q-0560 (angle may be left empty); Q-0570 (wall field limits) |
| D-Validate | One field's text `t`: `t.trim() === ''` → optional: value `null`; required: refused with `LENGTH_REFUSED_MESSAGE_KEY` (length) or `TURN_REFUSED_MESSAGE_KEY` (angle). Else length → `parseLength(t, field.lengthKind)` (EZD-201 E7; refusal key is its `messageKey`); angle → `parseTurnAngle(t)`. | 04 Measurement entry; Q-0561 (refusal message); EZD-201 E3 |
| D-Open | `{ type: 'open', text, anchor }` when closed: `open: true`, `active: 0`, `texts` = `text` at index 0 and `''` elsewhere, `error: null`, `anchor` as given; `handled: true`. When already open it acts as `append`. | 04 Measurement entry ("typing a number opens an inline length box"); S03 Tab |
| D-Edit | `edit` sets `texts[active]` to `text` and `error` to `null`; `append` adds `text` to the end of `texts[active]` and sets `error` to `null`. Both `handled: false` and no change when closed. | (reducer rule) |
| D-Tab | `tab` when open: if `texts[active]` is not empty and refused → stay, `error` = its key. Otherwise `active` = `(active + 1) % n`, or `(active - 1 + n) % n` when `back`, `error: null`. A one-field tool stays on field 0. `handled: true`. Closed → `handled: false`, no change. | S03 Tab ("moves to the next field") |
| D-Enter | `enter` when open: validate fields in order; first refused field → `active` = its index, `error` = its key, `open` stays `true`, no commit. All pass → `commit` = object with every field id → value (`number \| null`); new state = closed initial state (D-Init). `handled: true`. Closed → `handled: false`. | 04 Measurement entry (Enter commits); AC-5 (field stays open) |
| D-Esc | `escape` when open → closed initial state, `handled: true`, no commit. Closed → `handled: false` (the tool's own Esc runs: Q-0568 segment cancel, then no tool). | S03 Esc ("Cancels current operation"); Q-0568 |
| D-Init | `initialTypedEntryState(tool)` = `{ open: false, active: 0, texts: tool.fields.map(() => ''), error: null, anchor: 'cursor' }`. | (reducer rule) |
| D-Keys | The layer adds one `keydown` listener on `window` with `{ capture: true }`, only while `tool !== null && canEdit`. Event target is the box input → do nothing (the input's handler runs). Closed: `isOpenKey(e)` and not `isTypingTarget(e.target)` → `preventDefault()`, `stopPropagation()`, dispatch `open` with `text: e.key`, `anchor: 'cursor'`. Open (target not the input, not a typing target): a digit (`isOpenKey`) → `append`, then focus the input; `Tab` (with `shiftKey` → back), `Enter`, `Escape` → that action. Every key the listener acts on gets `preventDefault()` and `stopPropagation()`; others pass untouched. The input's `onKeyDown`: `Tab`, `Enter`, `Escape` → `preventDefault()`, `stopPropagation()`, dispatch; any other key → `stopPropagation()` only (so tool shortcuts never fire while typing). | 04 Measurement entry; S03 Enter, Tab, Esc; contract for EZD-210 (section 3 C17) |
| Focus | When `open` turns true, a layout effect focuses the input. Blur never closes the box; only Enter (commit) and Esc close it. | 04 (Enter commits); S03 Esc |
| D-State | `useState` holding `TypedEntryState` plus a ref mirror. Every handler computes `step = reduceTypedEntry(tool, ref.current, action)` synchronously, sets the ref and state, then calls `onCommit(step.commit)` when non-null, outside any state updater, so one Enter calls `onCommit` exactly once (also under React StrictMode). | ticket Done-when ("emits one commit") |
| Tool change | The layer renders its inner part with `key={tool.id}`, so a new tool, or the tool going null and back, starts from D-Init. | (state rule) |
| Hidden | `tool === null` or `canEdit === false` → the layer renders nothing (no root element) and registers no listener. | Q-0570 (bar only with a tool active); Q-0568 (without Edit model the bar is hidden) |
