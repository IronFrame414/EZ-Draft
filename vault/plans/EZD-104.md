### Failure and edge cases
| Function or action | Case | Behaviour | What the user sees |
| --- | --- | --- | --- |
| Search input | empty or only spaces | `q` trims to `''`; all rows | Full list |
| Search input | over 1,000 characters | `maxLength` stops typing at 1,000 | Nothing extra |
| Search input | `%`, `_` or `\` typed | matched literally | Rows containing that character, else "No users match" |
| Search input | fast typing | each change aborts the previous load | Skeleton, then the last text's rows |
| Route | `q` over 1,000 after trim, or `page` `0`, `01`, `-1`, `1.5`, `abc`, `1000000` | 400 `invalid_input` | (not reachable from the panel) |
| Route | no session / no `settings_users` | 401 / 403 | Panel: inline error with Retry |
| Route | `list_users` fails or returns a bad shape | reported once, 500 `db_unavailable` | Inline error "Couldn't load users." with Retry |
| Panel load | offline or network error | fetch rejects | Inline error with Retry; status bar keeps the last counts |
| Panel | selected row gone after a reload | selection cleared | Inspector "Select a user" |
| Up / Down | no rows (no match) | table not rendered; nothing to move | — |
| Pager | double click on Next | second click lands on the disabled button or the next page; each page change is one load | Correct page |
| `touchLastActive` | database error, 42501, throw | never rejects; 42501 ignored; others reported with `alert: false` | Nothing; the request answers as usual |
| `touch_last_active` | invited or deactivated membership, no claim, ended session | returns false, writes nothing | — |
| `formatLastActive` | time in the future (clock skew) | `diff < 60,000` → Now | "Now" |
| `formatLastActive` | 40 min across midnight | minutes rule comes first | "40 min ago" |
| `list_users` | `p_page` null or below 1 | treated as 1 | — |
| `list_users` | member with role null | `role` null in JSON | No pill |
