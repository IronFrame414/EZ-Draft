`runChecks` steps (each check: `try { checks[id] = (await fn()) === true } catch { checks[id] = false }`; every poll `expect.poll(…, { timeout: 10_000 })`, planner's choice, inside the app config's 60,000 ms test timeout):
1. `page.goto(SW_OFFLINE_PAGE)`.
2. `registered`: poll `data-sw-state` of `sw-offline-probe` is `'registered'`.
3. `controlled`: poll `navigator.serviceWorker.controller !== null`.
4. `page.reload()`; `r2` = `data-render-id` of `sw-offline-page`.
5. `cached`: poll `caches.open(SW_OFFLINE_CACHE).then((c) => c.match(location.href, { ignoreVary: true })).then((r) => r !== undefined)` is `true`.
6. goOffline.
7. `offline_flag`: `navigator.onLine === false`.
8. `offline_reload`: `page.reload()` resolves.
