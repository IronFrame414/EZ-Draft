# EZD-265 · Fix: the launcher sets aside any stuck ticket unit and goes on; a ready ticket with no plan fails the ledger check

- **ACs:** AC-EZD-265-1, AC-EZD-265-2, AC-EZD-265-3

- **User-visible result:** when one ticket's build or plan unit gets stuck, the launcher blocks that ticket with a note and carries on with the next unit instead of stopping; a ticket marked ready without a plan is caught by the ledger check.
