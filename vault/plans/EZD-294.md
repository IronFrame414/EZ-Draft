# EZD-294 · Object numbers

- **ACs:** AC-EZD-294-1, AC-EZD-294-2, AC-EZD-294-3
- **Complexity:** high
- **Areas:** data-model, migrations, testing
- **User-visible result:** nothing new on screen yet; every wall (and later every door and window) keeps one fixed number, the same on every device, that the conflict list will show as "Wall 4" (EZD-299).
- Phase: 4 · Planned by: planner · Date: 2026-11-07 · Status: questions

## 1. What to build
Data: no new table or column. `model_object.data.attributes.number` (jsonb) on `wall` and `opening` rows; `CURRENT_SCHEMA_VERSION` stays 3 (Q-0625 (a)). One migration: a keep-number trigger and a one-time backfill. No money field.

Rule (Q-0625 (a); AC-EZD-294-1): a whole number ≥ 1 per project (all floors) and key (`wall`, `door`, `window`); a new object gets the key's highest number ever stored in the project (deleted rows included) + 1, so none is reused. `Room N` (EZD-205a) is untouched.

**SQL M1** (probed on the pinned PostgreSQL 17.11 against a temp copy of `model_object` in a rolled-back transaction, 2026-11-07; L-009):
```sql
create function private.backfill_object_numbers(p_project uuid)
returns integer language plpgsql volatile security invoker set search_path = '' as $$
declare v_count integer;
begin
  with keyed as (
    select o.project_id, o.object_id, o.created_at,
      case when o.type = 'wall' then 'wall' else o.data #>> '{attributes,kind}' end as k,
      o.data #> '{attributes,number}' as num
    from public.model_object o
    where (p_project is null or o.project_id = p_project)
      and jsonb_typeof(o.data -> 'attributes') = 'object'
      and (o.type = 'wall' or (o.type = 'opening' and o.data #>> '{attributes,kind}' in ('door', 'window')))
  ), highs as (
    select project_id, k, max(v) as top
    from (select project_id, k, case when jsonb_typeof(num) = 'number' then num::numeric end as v from keyed) x
    where v >= 1 and v = trunc(v)
    group by project_id, k
  ), todo as (
    select project_id, object_id, k,
      row_number() over (partition by project_id, k order by created_at, object_id) as n
    from keyed where num is null or jsonb_typeof(num) = 'null'
  )
  update public.model_object o
  set data = jsonb_set(o.data, '{attributes,number}', to_jsonb((coalesce(h.top, 0) + t.n)::integer))
  from todo t left join highs h on h.project_id = t.project_id and h.k = t.k
  where o.project_id = t.project_id and o.object_id = t.object_id;
  get diagnostics v_count = row_count;
  return v_count;
end $$;
revoke all on function private.backfill_object_numbers(uuid) from public;

create function private.model_object_keep_number()
returns trigger language plpgsql security invoker set search_path = '' as $$
begin
  if jsonb_typeof(old.data #> '{attributes,number}') = 'number'
    and jsonb_typeof(new.data -> 'attributes') = 'object'
    and (old.type = 'wall' or (old.data #>> '{attributes,kind}') is not distinct from (new.data #>> '{attributes,kind}'))
    and (new.data #> '{attributes,number}') is distinct from (old.data #> '{attributes,number}')
  then
    new.data := jsonb_set(new.data, '{attributes,number}', old.data #> '{attributes,number}');
  end if;
  return new;
end $$;
revoke all on function private.model_object_keep_number() from public;

create trigger model_object_keep_number
  before update on public.model_object
  for each row when (old.type = new.type and old.type in ('wall', 'opening'))
  execute function private.model_object_keep_number();

select private.backfill_object_numbers(null);
```
Each statement gets a one-line comment citing this plan (pattern: the level-check migration header).
