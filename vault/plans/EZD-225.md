### Failure and edge cases
| Function or action | Case | Behaviour | What the user sees |
| --- | --- | --- | --- |
| Rail state | model loaded, lock state not loaded yet (`LockState.loaded` false, EZD-126 section 3) | treated as loading for a viewer with Edit model: every tool disabled, no note (S03:139 "tools disabled until model loads"; no edit may start before the lock is known, S03:16) | skeleton gone, rail disabled, no note |
| Rail state | lock state loaded, viewer without Edit model | the lock state is not read for the rail (Select only, AC-EZD-225-2) | Select-only rail |
| Rail state | the canvas failed to start (`canvasFailed`) | unchanged from develop: the rail is disabled (`selection-controller.ts:368-369`) | EZD-120c's canvas error state |
| Lock lost while drawing | the holder changes while a drawing gesture or typed entry is open | the gesture is cancelled as Escape cancels it, nothing is committed, the active tool becomes Select, the rail turns paused (S03:143; Q-0630 row 36 Esc) | the preview disappears; paused rail and note; EZD-126's lock-lost banner |
| Lock lost while dragging a selection | the holder changes mid-drag | the drag is cancelled and the objects return to where they were; nothing is committed (S03:143); a save already queued is EZD-125's (refused with `stale_lock_epoch`, Q-0697 03-data-model) | objects snap back; paused rail |
| Lock gained | Start editing succeeds (EZD-126) | tools enable; active tool Select; note removed (S06:78) | full rail |
| Paused tool | click, tap or Enter on a paused button | nothing (the button is `disabled`) | no change |
| Drawing key | E, V, M, W, D, C, K, L, T while paused or without Edit model | ignored, no message (S06:82) | no change |
| Edit keys | Delete, Backspace, Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z, Ctrl/Cmd+D, Ctrl/Cmd+C, Ctrl/Cmd+V while paused | ignored (S03:17 Edit model "also requires holding the edit lock"; Q-0633 Copy hidden for view-only) | no change |
| Select keys | Esc, Ctrl/Cmd+A, Shift+click while paused | work as for a view-only user (Q-0630 row 9; Q-0633 Select more and Select all) | selection changes |
| Offline | the holder goes offline | keeps the lock (S03:142); tools stay enabled | full rail |
| Offline | a non-holder goes offline | stays paused; Request edit disabled is EZD-126's (S06:104) | paused rail |
| Two tabs | the holder opens a second tab | both tabs hold the lock, both have full rails (Q-0697 03-data-model "the lock is per user") | full rail in both |
| Inspector | a read-only user clicks a field | no input is rendered (EZD-213b view_only text) | plain text |
