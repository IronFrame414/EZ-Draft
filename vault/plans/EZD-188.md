**R1 `scanWorkflowLines(lines)`** (the one `uses` extraction; placed directly after `quoteReadable`, before `cacheUses`). New constants:
`USES_WORD_RE = /(?<![A-Za-z0-9_-])uses(?![A-Za-z0-9_-])/gi`; `KEY_LINE_RE = /^[ \t]*(?:-[ \t]+)*["']?[A-Za-z_][A-Za-z0-9_.-]*["']?[ \t]*:(?:[ \t]|$)/`.
Keep `let open = null` (the indent of the last line whose last `uses` value ran to its end). For each line `l` at index `i`:
1. `n = i + 1`, `t = l.trim()`, `ascii = ASCII_LINE_RE.test(l)`; when `ascii && t.startsWith('#')` produce no entry and keep `open`.
2. `readable = ascii && quoteReadable(l) && !NODE_START_RE.test(stripCacheComment(l))`; `body = readable ? stripCacheComment(l) : l`; `problems = []`, `uses = []` (EZD-148 R1, unchanged text).
3. When `open !== null` and `body.trim() !== ''`: if `!KEY_LINE_RE.test(body) && indentOf(l) > open`, push `uses value continued at line ${n}`; then `open = null`.
4. If `t` matches `/^(-\s+)?\?(\s|$)/` push `explicit key at line ${n}`; if `!readable` push `unreadable quoting at line ${n}`.
5. `keys = 0`. For each match `m` of `body.matchAll(USES_KEY_RE)`: `keys += 1`; `flow = /[{\[]/.test(body.slice(0, m.index + m[1].length))`; `rest = body.slice(m.index + m[0].length)`; `parts = flow ? rest.split(/[,}\]]/) : [rest]`; `raw = parts[0].trim()`; if `parts.length === 1` set `open = indentOf(l)`; if `raw === ''` or `/^[>|*&!]/.test(raw)` push `unreadable uses value at line ${n}` and go to the next match; else push `raw.replace(/^["']/, '').replace(/["']$/, '').trim()` to `uses` (case kept).
6. If `[...body.matchAll(USES_WORD_RE)].length > keys` push `uses word not read as a key at line ${n}`.
7. Push `{ n, body, problems, uses }`.
This must be the only `.matchAll(USES_KEY_RE)` in the file (T4).

**R2 `cacheUses(lines)`**: `found = []`; for each entry: `found.push(...problems)`; for each `v` of `uses`: `value = v.toLowerCase()`, push `${value} at line ${n}` when `/^actions\/cache(\/|@|$)/.test(value)`; then the two existing `CACHE_KEY_RE` / `PM_CACHE_RE` checks on `body`, same messages as today. Return `found`.

**R3**: `LISTED_ACTIONS = ['actions/checkout', 'actions/setup-node']`; `FULL_SHA_RE = /^[0-9a-f]{40}$/`. `isListedUse(v)`: `at = v.indexOf('@')`; true only when `at > 0`, `LISTED_ACTIONS.includes(v.slice(0, at).toLowerCase())` and `FULL_SHA_RE.test(v.slice(at + 1))`. `unlistedUses(lines)`: for each entry of `scanWorkflowLines(lines)`: `found.push(...problems)`; for each `v` of `uses` with `!isListedUse(v)` push `uses not on the allowed list at line ${n}: ${v}`. Placed directly after `cacheUses`.
