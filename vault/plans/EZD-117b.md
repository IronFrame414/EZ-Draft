## 1. What to build

Data: no table or column. M3 re-creates P117a's two `security invoker` functions with `p_search` (RLS unchanged, P117a "Visible projects"). M1/M2 plus these edits ran on the pinned stack (PostgreSQL 17.11) in a rolled-back transaction, 2026-10-29 (L-009): client and address matches, case-insensitive, literal `%`/`_`, null and `''` = all, tab + search combined.

M3 `supabase/migrations/<ts>_add_project_search.sql`, in this order:
1. `drop function public.list_projects(text, text, jsonb);` then P117a M1 verbatim with three edits: signature `(p_sort text, p_status text default null, p_after jsonb default null, p_search text default '')`; a first CTE `term as (select replace(replace(replace(btrim(coalesce(p_search, '')), '\', '\\'), '%', '\%'), '_', '\_') as t),` before `base`; in `base`, `cross join term` after the `left join public.customer c …` line and one more `where` condition `and (term.t = '' or p.name ilike '%' || term.t || '%' or p.address ilike '%' || term.t || '%' or c.name ilike '%' || term.t || '%')`. Then `revoke all on function public.list_projects(text, text, jsonb, text) from public, anon, service_role; grant execute on function public.list_projects(text, text, jsonb, text) to authenticated;`
2. `drop function public.count_projects();` then P117a M2 with: signature `(p_search text default '')`; body prefixed `with term as (<same select>)`; `from public.project p left join public.customer c on c.id = p.customer_id cross join term`; `where p.archived_at is null and (<same search condition>)`. Then revoke/grant on `public.count_projects(text)` as above (L-016).
Header comment cites this plan. `language sql stable security invoker set search_path = ''` as in M1/M2 (lesson EZD-018).
