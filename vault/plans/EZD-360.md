### Decided for the builder
| Choice | Decision | Source |

| D-Rank | `phaseRank(56)` is 5.5. Every other number returns itself, unchanged; no validation, no throw. A single constant map, one entry | Josh 2026-11-07; Q-0630 |
| D-Sites | In `next_ticket.mjs`: each `.sort((a, b) => a - b)` over phases uses `comparePhases`; each `a.phase - b.phase` uses `comparePhases(a.phase, b.phase)`; each `<`, `<=`, `>`, `>=` between two phases compares ranks; `Math.min` and `Math.max` over phases pick by rank and return the phase number, never the rank. | D-Tags | A release tag's format is unchanged. `phase-5.3` sorts before `phase-56`, `phase-56.2` before `phase-6`. `release-name.mjs` needs no change: it orders only through `compareReleaseTags` | `scripts/release/tags.mjs:19`; `scripts/release/release-name.mjs:8,29` |
