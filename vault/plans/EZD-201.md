### Decided for the builder
`parseLength` algorithm, in this order (D1–D9); `formatLength` (D10–D14).

| Choice | Decision | Source |
| --- | --- | --- |
| D1 Location | Pure TypeScript in `@ezdraft/geometry`, no imports, no DOM, no Node APIs; runs in browser, Web Worker and Node. | architecture `Folder layout` (packages/geometry); 11 Where each output is produced |
| D2 Pre-checks | `s = text.trim()`. `s.length === 0` or `s.length > 32` → refuse `format`. 32 bounds the work; the longest form in the sources (`200' 0 1/16"`) is 12 characters. | planner, robustness (CLAUDE.md rule 18); 09j rows |
| D3 Quote marks | After trimming, replace U+2018 and U+2019 with `'`, and U+201C and U+201D with `"`. Primes U+2032, U+2033 and any other mark are not replaced, so they refuse `format`. | Q-0561 (straight or curly quote marks); Q-0570 (curly marks as tablet keyboards type them; anything else refused) |
| D4 Grammar | Whole match, one of three shapes, tried in order; regexes in E8. **A** decimal feet alone: `^(\d+(?:\.\d+)?)'$`. **B** whole feet, then a hyphen right after the mark or zero or more spaces, then an inch part, then an optional `"`. **C** an inch part alone, then an optional `"`. Inch part, three alternatives tried in this order: a whole number, then one or more spaces or one hyphen, then `<int>/<int>`; or a lone fraction `<int>/<int>` (`1/2"` = 0.5, `12' 1/2"` = 144.5, Q-0582 (a)); or a number `\d+(?:\.\d+)?`. `\d` is ASCII 0–9 only (no `u` flag). Spaces are U+0020 only, and only after the foot mark and between the whole number and the fraction. Anything that matches none of A, B, C refuses `format`. | 01 Conventions; 04 Measurement entry; Q-0561; Q-0570 (12 1/2, 6-1/2", 6.5", 12' 6 accepted; anything else refused); Q-0582 (a) (lone fraction accepted as inches); 09j rows 1–24 |
| D5 What the grammar refuses | `12 6`, `12 6"` (no fraction, Q-0561, 09j row 9); any sign, so `-5"` and `+5"` (no accepted form has one, Q-0570); `.5"`, `5."`, `12,5'`; a space before a mark (`150 "`, `12 '`); spaces around a hyphen (`12' - 6"`, `6 - 1/2"`) or the slash (`1 / 2"`); decimal feet followed by inches (`12.5' 3"`; 12.5' is shown only alone, 09j row 4); two foot marks (`12'6'`). A fraction with no whole number is not refused (D4, Q-0582 (a)). | Q-0570 "anything else is refused" |
| D6 Fraction rule | Denominator 0, or numerator ≥ denominator → refuse `format`. Any other denominator is accepted (the value is rounded in D8). | 03g Typed lengths (rounded to 1/16 when read); 09j rows 2, 7, 12, 16–19 (proper fractions only) |
| D7 Value | A: feet × 12. B: feet × 12 + inch part. C: inch part. Inch part with a fraction: whole + numerator / denominator; a lone fraction: numerator / denominator. Inches after feet may be 12 or more (`12' 15"` = 159): the shape is the listed `12' 6"` shape and no source limits the inch part. Leading zeros are allowed (`0150"` = 150). | 09j; Q-0570 (shapes) |
| D8 Rounding | `inches = Math.floor(value * 16 + 0.5) / 16` (nearest 1/16, halfway up). | 03g Typed lengths (*settled here*); 09j row 10 |
| D9 Field limits | Only when `kind === 'wall_room'`, after D8: `inches <= 0` → refuse `not_positive`; `inches > 2400` → refuse `over_max`. `kind === 'other'` has no range check (0" accepted). Checks run D2 → D9 in order, so a malformed text always reports `format`. | Q-0568 (above zero, at most 200 ft); Q-0570 (wall and room fields only, after rounding; other fields accept 0"); 03g row 9 |
| D10 Refusal result | Every refusal returns `{ ok: false, reason, messageKey: 'office.length.refused' }`: one message for every reason. | AC-EZD-201-5; Q-0561; S01 Validation (`S01-projects.md` line 110) |
| D11 Message namespace | `office.` key, English only: length boxes in phases 2–4 are office screens (S01 wizard, S03 editor). A phone screen that types lengths later adds its own Spanish key. | architecture `Messages and language (t())` (office keys English only) |
| D12 Display rounding | `n = Math.floor(inches * d + 0.5)` (units of 1/d inch; halfway up), then integer maths: `feet = Math.floor(n / (12 * d))`, `rem = n - feet * 12 * d`, `whole = Math.floor(rem / d)`, `num = rem - whole * d`; reduce `num/d` by their greatest common divisor. Rounding carries into inches and feet (143.75 → `12' 0"`). | Q-0207; 09j rows 10–12; 03g rows 6–9 |
| D13 Display text | feet > 0: `<feet>' <whole>"` or `<feet>' <whole> <num>/<den>"` (whole always shown, `1' 0 1/2"`, `10' 0"`). feet = 0: `<whole>"`, `<whole> <num>/<den>"`, or `<num>/<den>"` when whole is 0 and num > 0 (`5/8"`); 0 → `0"`. Straight ASCII marks, one space between parts, no digit grouping. | 09j rows 1–24 (`6 1/2"`, `1' 0 1/2"`, `200' 0"`); 03g row 9; Q-0568 (S02 board "5/8" gap") |
| D14 Bad display input | `formatLength` throws `RangeError` when `inches` is not finite or is below 0, or when `denominator` is not 2 or 16 (runtime check; the type is `2 \| 16`). | planner: lengths are never negative (Q-0568); a bad call is a programming error |
| D15 Which precision a caller uses | Not this ticket: callers pass `PLAN_DISPLAY_DENOMINATOR` (walls, rooms, plans) or `DETAIL_DISPLAY_DENOMINATOR` (cabinets, details). The Settings choice (Q-0207 "changeable in Settings") is a later ticket's. | Q-0207; 01 Conventions |
| D16 Tests' non-ASCII data | Written as escapes: `'12’6”'`, `'12‘ 6“'`, `'12″'`. | lesson L-042 |
