# EZD-347 · Fix: the offline banner shows its cloud_off icon

- **ACs:** AC-EZD-347-1, AC-EZD-347-2, AC-EZD-347-3
- **Complexity:** medium (section 8)
- **Areas:** ui, testing, docs, scripts
- **User-visible result:** when the connection drops, the Offline banner shows its cloud icon, and any other icon drawn for the first time while offline shows too, instead of a blank gap.
- Phase: 3 · Planned by: planner · Date: 2026-11-06 · Status: planned

## 1. What to build

**Cause (section 2 Probe).** `Icon` uses `<use href="/icons/sprite.svg#<name>">`, and each new `<use>` requests the file again. `OfflineBanner` renders only while offline (`useOnline`), so that request fails and the icon draws 0 × 0, in Chromium and WebKit, even after other icons loaded the sprite. The `error` icon renders online, so it shows. Font, file and symbol are correct.

**Fix.** The root layout renders the sprite inline (`<svg display="none">`, symbols `ez-icon-<name>`), and `Icon` points at `#ez-icon-<name>`, so no icon needs a request. This is still an SVG sprite (04 Type; 11 rule 8). The data is a generated module that only server code imports (11 Download size).
