| Area | `ringSignedAreaSqIn` = shoelace / 2 (CCW positive); `outlineAreaSqIn` = its absolute value; `roomAreaSqFt` = `Math.floor((outlineAreaSqIn(b) + 72) / 144)`; fewer than 3 points → 0. Never stored | Q-0207; Q-0568 (halves up); 03g; 11 rule 2 |
| `pointInRing` | even-odd: count edges `(a,b)` with `(a.y > p.y) !== (b.y > p.y)` and `p.x < a.x + (p.y − a.y)(b.x − a.x)/(b.y − a.y)` | standard even-odd (plan choice) |
| `interiorPoint` | (1) `c` = area centroid (shoelace centroid; signed area 0 → vertex average); `pointInRing(c)` → `c`. (2) else at `y = c.y` collect the crossing x of every edge by the half-open rule above, sort ascending, pair (0,1), (2,3)…; return the midpoint of the widest pair (first on a tie), `y = c.y`. (3) no crossings → `c` | plan choice; label anchor and matching need one deterministic inside point |
| `sameBoundary(a, b)` | same length `n` and some offset `k` and direction `d ∈ {+1, −1}` with `pointsEqual(a[i], b[(k + d·i) mod n])` for all `i` | 03g (1/64" inclusive); `pointsEqual` from `G/src/tolerance.ts` |
| Outline graph | Walls of `level` (case-insensitive compare, as `findWallJoins`), skipping walls with `wallLength ≤ COMPARISON_TOLERANCE_IN`. Vertices: every wall end, plus for each wall the points `findWallJoins` (`G/src/walls/joins.ts`) reports on it: `tee-on` → the other wall's `otherEnd` point; `cross` → the drawn lines' intersection (private `lineIntersection` in outlines.ts). Points within `pointsEqual` share one vertex (first seen wins; walls in input order, start then end, then join points). Each wall is cut at its vertices, sorted by position along it; an edge whose vertex pair (either order) already exists is dropped (the earlier wall owns it) | Q-0570 (dividing wall, crossing joins); Q-0598 (a); P203 Decided Joins, Degenerate walls |
| Faces | Half-edges both ways per edge. At each vertex, outgoing half-edges sorted by `Math.atan2` ascending. `next(u→v)` = the outgoing half-edge at `v` just before the twin `v→u` in that order (wrapping). Faces = cycles of `next`. Drawn signed area `> 0` → room face; `≤ 0` → the outer face of its connected component | standard planar face walk (plan choice) |
| Face line | For a half-edge that runs start→end of its wall: `wallFaceLines(data).left` (`G/src/walls/wall.ts`); end→start: `.right`. The face is always on the half-edge's left | Q-0559; Q-0569 (b); 09j Thickness side; P203 Face offsets |
| Ring vertices | For each vertex `V` between consecutive half-edges `a`, `b` of a cycle: if the face lines' directions are not parallel (`|cross(dA, dB)| > 1e-12·|dA|·|dB|`), the infinite lines' intersection, `p = a.start + dA·t`, `t = cross(b.start − a.start, dB) / cross(dA, dB)` with unnormalised `dA`, `dB`; if parallel, `V` projected on `a`'s line then on `b`'s line (both, one if `pointsEqual`). Then drop consecutive `pointsEqual` duplicates (wrapping) and repeat: drop `r[i]` when its distance to line `r[i−1]`–`r[i+1]` ≤ 1/64" and `dot(r[i] − r[i−1], r[i+1] − r[i]) > 0` | 03g; plan choice (a free wall end gets a square cap) |
| Room rings | From room faces; keep a ring only if it has ≥ 3 points and `ringSignedAreaSqIn > 0`; rotate it to start at its vertex with the smallest `y`, then smallest `x`. Clean-up and rotation run on each ring before holes are joined; the joined ring is not cleaned again | plan choice (deterministic; P221 template corners already start at (0,0)) |
| Walls not dividing a room | Wrapped by the ring, so their footprint is outside the area: a stub with a free end gets its cap (T9). A component that does not touch the room's walls (a free wall, a closed box) is a hole: its outer-face ring (from the same face-line rule; must have `ringSignedAreaSqIn < 0`) is assigned to the smallest-area room ring of another component that holds the component's first half-edge's start point (`pointInRing`). Holes join their room as one keyhole ring: holes by largest max-x vertex `M` first (ties smallest y); ray +x from `M`; nearest crossing `I` with the current ring's edges (half-open rule, x > M.x); splice `…, r[i], I, M, (hole from M in its own order), M, I, r[i+1], …`; when `I` is `pointsEqual` to `r[i]` or `r[i+1]`, that vertex stands for `I`; no crossing → the hole is dropped | QP-1 (recommended (a)); Q-0559 (outline on the inside finished face) |
| Outline order | Sorted by `boundary[0].y`, then `boundary[0].x`, then `outlineAreaSqIn` ascending | plan choice (deterministic) |
| `wallIds` | Ids of every wall with a half-edge in the room's cycle or in one of its holes' cycles, unique, in the walls' input order | P205 part b (absorb needs "walls of that room") |
| Reconcile scope | Only rooms with `data.level` equal (case-insensitive) to `level`; rooms on other levels never appear in the result. A stored room whose `closureOverride` is not `null` takes part in matching steps (1) and (2), so the outline it pairs with makes no create, but it is never updated or deleted here (a pair with it is "no change"; EZD-205b replaces this rule with its gap check) | P205 part b; Q-0568 |
| Reconcile matching | (1) Stored rooms in object order: pair with the first unpaired outline (outline order) where `sameBoundary` → no change. (2) Candidates among the rest: `(s, o)` when `pointInRing(interiorPoint(o.boundary), s.boundary)` or `pointInRing(interiorPoint(s.boundary), o.boundary)`; sorted by `outlineAreaSqIn(o)` descending, then `outlineAreaSqIn(s)` descending, then outline index, then object index; take a pair when both are free → update.
