## 1. What to build
Model inches, y up; angles in degrees, counter-clockwise from +x [SP]. `d` = unit vector start→end, `L` = length, `n` = left normal `(−d.y, d.x)`, `t` = thickness, `P(s)` = start + d·s. Face offsets along n by `thicknessSide`: `right` → `oL = 0`, `oR = −t`; `left` → `oL = t`, `oR = 0`; `center` → `oL = t/2`, `oR = −t/2`.
