**1a. RM.**
- `reportProblems(text, name)`: lines = `text.split('\n')` with a trailing `\r` removed. Line 1 not exactly `---`, or no later line exactly `---`: return `['no front matter']`, preceded by P6 when `name` starts with `.`. Otherwise, between the two, each line with a `:` gives key = text before the first `:` trimmed, value = the rest trimmed with every `|` turned to `/`; only `title`, `scope`, `ticket` are kept, a later duplicate wins (all as `parse()` today). Problems in this order: P6 when `name` starts with `.`; `missing title`, `missing scope`, `missing ticket` for each empty or absent one; P5 when `ticket` is present and does not match `TICKET = /^(?:EZD-\S+|Q-\d{4})$/` (Q-0376 (a); T8's widened row pattern, E2). `[]` means complete.
- `parse()` becomes a private `fields(text): { title?, scope?, ticket? } | null` (null = no front matter) holding the parsing rules above; `reportProblems` and `adopt` both call it. `adopt`: a non-empty `reportProblems(text)` skips the file with reason `problems.join('; ')`; otherwise the line uses `fields(text)`'s values as today. Everything else unchanged (T1 to T7 stay green).
- `checkPending(researchDir)`: entries of `<researchDir>/pending` (none when the folder is absent), sorted; an entry that is not a file is skipped, as adopt does; a read error throws and the CLI's existing catch prints `research: <message>` with exit 1; for each file: a name ending `.md` (dot names included) counts toward `count` unless it starts with `.`, and adds `pending/<name>: <p>` for each problem of `reportProblems(text, name)`; `.gitkeep` with size > 0 adds `pending/.gitkeep: ` + P7. Other files are ignored.
- `checkIndex(researchDir)` (Q-0377 (a); mirrors T8's store assertions, R18). Private `HEADER` = `vault/research/INDEX.md` lines 1-4 plus their newlines, character for character (equals T8's `header`); `ROW = /^R-\d{3,} \| \d{4}-\d{2}-\d{2} \| [^|]+ \| [^|]+ \| (?:EZD-\S+|Q-\d{4})$/`. Steps: (1) `<dir>/INDEX.md` absent: return `[I1]`. (2) Text not starting with `HEADER`: return `[I2]`. (3) `rest = text.slice(HEADER.length).split('\n')`; for each line `i` (n = i + 5, the file's line number), skip `''`; no `ROW` match (no `\r` stripping, as T8): I3; else `id = line.split(' | ')[0]`; `id` seen before: I4; else record it, and `<dir>/<id>.md` not an existing file: I5. (4) Each entry of `<dir>` matching `/^R-.*\.md$/` (T8's filter), sorted, whose name without `.md` was not recorded: I6. Problems in that order; I3, I4 and I5 are each prefixed `INDEX.md line <n>: `.
- CLI: `check` (exactly one argument) runs `checkPending` then `checkIndex` on the same `researchDir` as `adopt`; problems = pending ones then INDEX ones; none: stdout K1 (count from `checkPending`), exit 0; else stdout K2 then one K3 line per problem, exit 1. Any other argument list: stderr U1, exit 2.
