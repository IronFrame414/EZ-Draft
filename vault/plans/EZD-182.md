**F**, the same line in all three files, exactly:
```text
const BUILD_FLAG_RE = /--(?:dangerously-allow-all-builds|config\.|allow-build)/i;
```

**R1, rule (m), in `checkWorkflow`**, run for every file name, over every line (not only `run:` lines):
```
// (m) pnpm flags that turn on build scripts (EZD-182; Q-0316 (a))
lines.forEach((l, i) => {
  if (l.trim().startsWith('#')) return;
  if (BUILD_FLAG_RE.test(l)) add('m', `pnpm build flag at line ${i + 1}`);
});
```
One problem per line, whatever the number of matches on it.

**R2, `buildFlagScriptProblems(text)`**, for one `package.json` text, in this order:
1. `JSON.parse(text)` throws, or the result is not a plain object (`null`, an array or a primitive): return `['unreadable']`.
2. `scripts` is absent (`undefined`): return `[]`.
3. `scripts` is `null`, an array or not an object: return `['scripts not an object']`.
4. For each `[name, cmd]` of `Object.entries(scripts)`, in that order: `typeof cmd !== 'string'` pushes `` `script ${name} not a string` ``; otherwise `BUILD_FLAG_RE.test(cmd)` pushes `` `script ${name}` ``.
5. Return the array.

**R3, `vercelBuildFlagProblems(text)`**, for one `vercel.json` text:
1. `JSON.parse(text)` throws, or the result is not a plain object (`null`, an array or a primitive): return `['unreadable']`.
2. Walk every value depth first, in `Object.entries` order and array index order, carrying a path: a top-level key `k` has path `k`; a key `k` under path `p` has `` `${p}.${k}` ``; array item `i` under `p` has `` `${p}[${i}]` ``.
3. A string value matching `BUILD_FLAG_RE` pushes `` `value at ${path}` ``. Numbers, booleans and `null` are skipped. Keys are not tested.
4. Return the array.
