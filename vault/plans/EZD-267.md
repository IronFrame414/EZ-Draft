Step 1 `planApproval`, in order: (a) status = STATUS.md row cell 4 trimmed (the `doneIds` parse); no row → `{ approved: false, reason: 'status none' }`; not in `APPROVED_STATUSES` → reason `status <s>`. (b) no plan file → `no plan`. (c) `problems = lintPlan(text)`; non-empty → `plan_lint: <problems[0]>`. (d) `{ approved: true, reason: null }`.

Step 1 `applyGrant`, in order: (1) `a = planApproval`; (2) `needs = grantNeeds`; (3) `needs` empty → `{ id, approved: a.approved, paths: [], written: false, reason: a.reason }`; (4) not approved → `{ id, approved: false, paths: needs, written: false, reason: a.reason }`, nothing read or written; (5) `readGrants(root)` (throws its `grants.json unreadable: …` errors); (6) copy every key except `id` and done tickets (`doneIds`); `entry` = sorted unique of (old `obj[id]` paths that `planPaths(plan)` still lists) plus `needs`; keys sorted; (7) text equals the file → `written: false`; else write it (Decided "Write") → `written: true`; return `{ id, approved: true, paths: entry, written, reason: null }`.

Step 1 `dropGrant`: `readGrants` (throws); no `id` key → `{ removed: false }` and nothing written (an absent file stays absent); else delete the key, write (Decided "Write"), `{ removed: true }`.

Step 1 CLI: `apply <T>` prints `JSON.stringify(applyGrant(...))`; `drop <T>` prints `JSON.stringify(dropGrant(...))`; a thrown error → stderr `<message>`, exit 1; bad ID or extra argument → the usage line, exit 2. Usage line: `usage: node vault/tools/grants.mjs needs <T> | patch <T> <path>... | apply <T> | drop <T>`.

Step 2 `commitOrRestore`: `r = commitPaths(root, [rel], msg)`; when it throws, or `r.skipped` is set, restore and throw (`e.message`, or `r.skipped` as the message): restore = `git reset -q -- <rel>` (result ignored), then `before === null` → unlink (missing ignored), else `writeFileAtomic(root, path.join(root, rel), before)`. Caller holds the ledger lock (`commitPaths` requires it).
