# EZD-277 · Fix: the write and read guards compare paths case-insensitively on a case-insensitive disk

- **ACs:** AC-EZD-277-1, AC-EZD-277-2
- **Complexity:** high
- **Areas:** tooling, security, testing

**D1 `caseInsensitiveDisk(dir)`**, in order: `dir` not a non-empty string → `true`; `flipped` = `dir` with every ASCII letter's case swapped (`/[A-Za-z]/g`, each `c` → `c === c.toLowerCase() ? c.toUpperCase() : c.toLowerCase()`); `flipped === dir` → `true`; `a = statSync(dir)` throws → `true`; `b = statSync(flipped)` throws → `false`; return `a.dev === b.dev && a.ino === b.ino`. Never writes a file.
**D2 `pathKey(p, fold)`**: `fold` false → `p` unchanged; true → `p.normalize('NFC').toUpperCase().toLowerCase().normalize('NFC')`.
**D3 `pathIn(list, p, fold)`**: `list.some((e) => pathKey(e, fold) === pathKey(p, fold))`.
**D4 `grantFor(grants, ticket, fold)`**: `null` unless `grants` is a plain object (`grants !== null && typeof grants === 'object' && Object.getPrototypeOf(grants) === Object.prototype`); `keys` = `Object.keys(grants)` filtered to those matching `ASCII = /^[\x20-\x7e]+$/` with `pathKey(k, fold) === pathKey(ticket, fold)`; `keys.length !== 1` → `null`; `v = grants[keys[0]]`; `v` an array whose every element is a string matching `ASCII` → `v`, else `null`.
Comment above D1-D4 (lesson EZD-152): `// Letter case (EZD-277): on a disk that ignores case, every judged path and every list entry, grant path and ticket key is compared as pathKey(…, true); the probe fails closed to folding. Grant keys and paths outside printable ASCII grant nothing.`
