# EZD-345 · Build system: commands outside the unit sandbox trust no git state the sandbox can write

- **ACs:** AC-EZD-345-1, AC-EZD-345-2
- **Complexity:** high (section 8)
- **Areas:** tooling, scripts, security
- **User-visible result:** none in the app; when the unit sandbox is back on, a unit cannot make the launcher, the worktree and merge steps, the ledger commits or the GitHub script run its hooks, follow its config or trust its refs, objects or locks.

## 1. What to build
Data: none.

**Trust rule (L-047; Q-0548 (a)):** a command that runs outside the unit sandbox trusts nothing the sandbox can write.
