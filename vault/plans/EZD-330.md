# EZD-330 · Fix: the Projects page tabs and other controls meet the 44 px touch-target check

- **ACs:** AC-EZD-330-1
- **Complexity:** low
- **Areas:** ui, testing, tokens
- **User-visible result:** on the Projects page every status tab, the sort button and each sort menu option can be tapped across a 44 px area, the page looks as on board S01, and develop's CI is green again.

## 1. What to build
Data: none.

Cause (read from merged code): EZD-289 E1 (`app/e2e/home-settings.spec.ts:20`) runs `expectTouchTargets(page, page.locator('main'))` (`app/test-harness/touch-targets.ts`) at the desktop project (1600 × 1000, fine pointer). `touch.module.css` `.target`/`.hitArea` apply only under `@media (any-pointer: coarse)`, so on desktop `.tab` (padding 7px, 13px text: 30 px tall, ticket row) and `.sortButton` (padding 9px + 18 px icon + 2px border: under 44) fail. `.menuItem` (padding 10px, 14px text) is under 44 too.
