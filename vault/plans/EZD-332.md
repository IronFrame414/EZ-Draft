# EZD-332 · Fix: the notification bell keeps zod out of the browser and loads its list on first open

- **ACs:** AC-EZD-332-1, AC-EZD-332-2
- **Complexity:** low (section 8)
- **Areas:** ui, testing, realtime, performance
- **User-visible result:** the bell looks and works as before, but the page with it downloads less code: the notification list's code comes down the first time the bell is opened, and zod never reaches the browser through the bell.
- Phase: 2 · Planned by: planner · Date: 2026-11-04 · Status: planned
