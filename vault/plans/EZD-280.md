**E1 `globReach`, tool `'Bash'`.** P3: `'Bash'` is handled as `'Glob'` (base `/` for an absolute alternative, else `root`; deep only when a folder part holds a wildcard). P6: when `ctx.tool === 'Bash'`, the `'env'` and `'signin'` kinds also need `F.startsWith('.')`, because a shell wildcard or bracket never matches a leading dot (probe F). `'Grep'` and `'Glob'` results are unchanged.

**K `shellWords(command)`** (POSIX shell words; KNOWN-LIMITS shell-guard entry). Walk the characters left to right, building one word (`text`, `glob`, `unreadable`) and one command (a list of words).
- **K1** End a word: when `text !== ''`, push it to the command; when `text` is exactly `[`, `[[`, `{`, `}` or `{}`, push it with `glob: false`. Start a new word. End a command: end the word; push the command to the result when it holds a word; start a new command.
- **K2** Unquoted space or tab ends the word. Unquoted `;`, `&`, `|`, `(`, `)`, `<`, `>`, backtick, `\n`, `\r` end the command. `#` is an ordinary character (no comments: zsh without `interactive_comments` runs the rest).
- **K3** Unquoted `\`: followed by `\n` → drop both; followed by any other character → append that character; at the end of input → append `\`.
- **K4** `'`: append every character up to the next `'` as is; no closing `'` → up to the end.
- **K5** `"`: up to the next unescaped `"`. Inside, `\` before `$`, backtick, `"` or `\` appends that character; `\` before `\n` drops both; `\` before any other character appends both. No closing `"` → up to the end.
- **K6** Unquoted `$` directly followed by `'` (ANSI-C quoting): drop the `$`, then up to the next `'` not escaped by `\`. Decode `\\` `\'` `\"` `\?` to the second character, and `\a` `\b` `\e` `\E` `\f` `\n` `\r` `\t` `\v` to their control characters. `\` before a digit, `x`, `u`, `U` or `c` sets `unreadable: true` and appends both characters undecoded. `\` before any other character appends both. Unquoted `$` directly followed by `"`: drop the `$`, then K5.
- **K7** Any other unquoted character is appended. `*`, `?`, `[`, and a `{` not directly after a `$` appended by K7, set `glob: true`. Characters appended by K3-K6 never set `glob`.
- **K8** At the end of input end the command. Return the commands in input order.

**J `shellSecretReason(command, cwd)`**: `home = realOr(os.homedir())`, `rr = repoRoot()`, `roots = [norm(cwd)]`, `cur = norm(cwd)`, `prev = cur`. Return `walk(command, 0)`.
- **J1 `walk(text, depth)`**: for each command `c` of `shellWords(text)`, in order:
  - Exempt word: `c[2]` when `c` is exactly 3 words `test`, `-f`, W, or exactly 4 words `[`, `-f`, W, `]` (texts compared exactly). Otherwise none.
  - When `c[0].text` is `cd` or `pushd`, with `a` = the last later word whose text does not start with `-`, or the word `-` when it is the only later word: no `a` → `next = home`; `a.text === '-'` → `next = prev`; `a.text` holds `$` or a backtick → `next = cur`; otherwise `next = targets(a.text, cur, home)[0]`. Then `prev = cur`, `cur = next`; push `cur` to `roots` when not already in it.
  - For each word `w` of `c` that is not the exempt word: `r = judge(w, depth)`; a non-null `r` is returned.
  - Return `null`.
- **J2 `judge(w, depth)`**, checks in this order, the first hit returns:
  1. `cands` = `w.text`, then the pieces of `w.text` split at `/[\s=:,]+/` (empty pieces dropped, repeats dropped). For each `s` of `cands`, each `root` of `roots`, each `t` of `targets(s, root, home)`: `k = secretName(t)` not null → B1(`s`, `k`).
  2. `w.unreadable && depth === 0` → B2(`w.text`).
  3. `w.glob`: `g` = `w.text` with a leading `~` or `~/` replaced by `home` (as `targets`). For each `root`: `r = globReach(root, g, { tool: 'Bash', home, repoRoot: rr })`. A kind → B3(`w.text`, `r`); `'unreadable'` and `depth === 0` → B2(`w.text`).
  4. Re-read, when `w.text` matches the class below and `shellWords(w.text)` is not exactly one command of one word whose text is `w.text` (a re-read that changes nothing stops here): `depth < 3` → `r = walk(w.text, depth + 1)`, non-null → return `r`; `depth === 3` → B2(`w.text`) (fail closed past three levels). The class: `/[\s'"\\`$;&|<>()]/`.
- **J3** `roots` and `cur` are shared by every `walk` level of one call.
- **J4** No hit → `null`.

**Texts** (section 6; `<what>` = `kindText[k]`; `shown` = the string judged, after quote removal):
- **B1** `` `Naming secret files in a shell command is not allowed: ${shown} is ${what} (Q-0461).` ``
- **B2** `` `Naming secret files in a shell command is not allowed: this word cannot be checked: ${shown} (Q-0461). Write it without $'…' number escapes or unbalanced brackets or braces.` ``
- **B3** `` `Naming secret files in a shell command is not allowed: ${shown} can match ${what} (Q-0461). Name the files without wildcards or braces.` ``
- **B4** (in guard-bash) `` `The secret-file check could not run (${msg}); this command is refused (Q-0461).` ``

**G1** (guard-bash.mjs): `// Secret files named anywhere in the command, whatever the command word (EZD-280; Q-0461 (a)): every word is judged by the read guard's secretName in secret-paths.mjs, failing closed.` then `let secretWhy = null; try { secretWhy = shellSecretReason(cmd, input.cwd || projectDir()); } catch (e) { secretWhy = B4 with msg = e && e.message ? e.message : String(e); } if (secretWhy) deny(secretWhy);`. `cmd` is the existing unmodified command string (newlines kept).
