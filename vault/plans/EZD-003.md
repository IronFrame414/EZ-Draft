Checks, all required, in this fixed order:

| id | Pass when | Source |
| --- | --- | --- |
| `dns` | `https.error.code` is not `ENOTFOUND` / `EAI_AGAIN`. The fail detail names the needs-from-josh DNS item | R24 #1 ("a subdomain added in DNS") |
| `tls` | No TLS error. Any `https.error.code` other than the DNS codes counts as a TLS or connection failure, e.g. `CERT_HAS_EXPIRED`, `ERR_TLS_CERT_ALTNAME_INVALID`, `UNABLE_TO_VERIFY_LEAF_SIGNATURE` | Done when "over HTTPS" |

| `host` | `new URL(finalUrl).protocol === 'https:'` and its `hostname === HOST` | R24 #1 address |
| `vercel` | `headers['server']`, compared case-insensitively, equals `vercel` | Ticket Scope "pointing to Vercel" |
| `title` | `body` has a `<title>` element whose text contains `EZ Draft` | vault/plans/EZD-001.md Step 2 (`metadata.title` = `EZ Draft`); 02 product name |
| `hsts` | A `strict-transport-security` header with `max-age=N` where N > 0 | Done when "over HTTPS". Vercel sends it by default: `max-age=63072000` on the apex (Oct 11) and on the subdomain (2026-10-18) |
| `redirect` | `http.status === 308` and `http.location` starts with `https://ezdraft.ezcontractorbinder.com` | Done when "over HTTPS" (plain HTTP must not serve the app). 308 observed on the apex (Oct 11) and the subdomain (2026-10-18) |
