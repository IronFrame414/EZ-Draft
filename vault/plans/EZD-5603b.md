# EZD-5603b · Assistant photo: control, browser shrink, server strip

- **ACs:** AC-EZD-5603-6, -7, -8, -11; AC-EZD-5603-10 (Photo, Remove photo); AC-EZD-5603-12 (photo stays after 429, 5xx, timeout); AC-EZD-5603-13 (4,000,000-byte body); AC-EZD-5603-14 (photo stays when the drain fails) (`vault/spec/acceptance-criteria.md:1869-1876`; clause split per `vault/plans/EZD-5603.md` AC map)

- **Areas:** ui, testing, security, api, dependencies
- **User-visible result:** In the Assistant panel Josh taps Photo, picks a JPG, PNG, HEIC or WebP up to 20 MB, sees it as a thumbnail with its name and size, and sends it with one prompt. The browser shrinks it, the server strips location data, and the next prompt goes without it.
