Draft rows O0 (paths of rows 1-10), P1, 1-10 (row 2: C15 only), 13 (without D9), 14, 15 (K1 only), J1, O3; D1-D8, D10; C1-C15 (C13 without `clearForUnit`), C17-C20; tests T1-T17, T19, T22-T26 (23); S1-S4.
- Done when: A call through the relay on a container, volume, network or exec it did not create is refused (test). A gate stack has its own project name and the gate removes the lane's builder stack before it starts (test). The full local gate passes through the relay (full gate).
- ACs: AC-EZD-355-1 and AC-EZD-355-2 move here with the texts above; AC-EZD-355-4 moves here; one new AC for the third sentence (`gen_acs.mjs`).

## 7. Security review
security-review: yes. Areas: permissions (who may act on which Docker objects), data access (host files containers reach), API (the Docker Engine API the relay filters).
Reviewers needed: code-reviewer always · calc-auditor no · ui-verifier no · security-reviewer yes (Fable 5.1, high).

Fail-closed: an unknown route, HostConfig key, bind path or label is refused; the relay is the real control for ezdraft and units, Docker Desktop file sharing (J1) behind it.
