# EZD-6001 · Floor switcher and floor tools

- **ACs:** AC-EZD-6001-1, AC-EZD-6001-2, AC-EZD-6001-3, AC-EZD-6001-4
- **Complexity:** high (section 8)
- **Areas:** ui, data-model, testing
- **User-visible result:** Josh picks which floor the plan shows; with Edit model he adds, renames and deletes floors, and deleting a floor that still has walls asks first and deletes them with it. View-only users can switch floors but cannot change them.
- Phase: 6 · Planned by: planner · Date: 2026-11-09 · Status: questions (Q-0666 open; QP-1)

## 1. What to build

Data: none new. A floor is a `model_object` of type `floor` (`floor.ts` `{ name, order }`); Create already makes "Floor 1", order 1 (migration `20261105200003`; Q-0508, Q-0664). Floor edits go through the model store and outbox like any object. No `schema_version` change, no money field.

Key: S = `app/src/editor/`. FV = `Pick<FloorView, 'getState' | 'subscribe'>`.
