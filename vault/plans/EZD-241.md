# EZD-241 · Fix: the release stops a migration that drops or renames a released object in production

- **ACs:** AC-EZD-241-1, AC-EZD-241-2, AC-EZD-241-3
- **Complexity:** high (section 8)
- **User-visible result:** from the second release on, while production's migrations run, two temporary database triggers stop any migration that would drop or rename something the previous release still reads, even when the drop happens only because of the rows production holds; they are removed after every run, and the runbook has a one-paste check (J5) for `ezdraft-dev`.
- Phase: 1 · Planned by: planner · Date: 2026-10-27 · Status: planned

### Guard SQL (`release-guard.mjs`)
`lit(s)` = `'` + `s` with every `'` doubled + `'`. `<LIST>` = `lit(JSON.stringify(objects.map(({ id, kind, name }) => ({ id, kind, name }))))`; `<SNAP>` = `lit(SNAPSHOT_SQL.replace(/;\s*$/, ''))` (`SNAPSHOT_SQL` imported from `scratch-check.mjs`); `<TAG>` = `lit(baseTag)`; `<IDEXPR>` = the `case` below. `buildGuardInstallSql` returns exactly:
```sql
begin;
create schema ezd_release_guard;
revoke all on schema ezd_release_guard from public;
create function ezd_release_guard.protected() returns table (id text, kind text, name text) language sql immutable set search_path = '' as $ezd_guard$
  select x.id, x.kind, x.name from pg_catalog.json_to_recordset(<LIST>::json) as x(id text, kind text, name text)
$ezd_guard$;
create function ezd_release_guard.on_sql_drop() returns event_trigger language plpgsql set search_path = '' as $ezd_guard$
declare
  r record;
  p record;
begin
  if coalesce(pg_catalog.current_setting('ezd.release_guard', true), '') <> 'on' then
    return;
  end if;
  for r in select d.classid, d.objid, d.objsubid from pg_catalog.pg_event_trigger_dropped_objects() as d loop
    select o.kind, o.name into p from ezd_release_guard.protected() as o where o.id = <IDEXPR>;
    if found then
      raise exception 'ezd_release_guard: % % is dropped or renamed while % still reads it', p.kind, p.name, <TAG>;
    end if;
  end loop;
end
$ezd_guard$;
create function ezd_release_guard.on_ddl_end() returns event_trigger language plpgsql set search_path = '' as $ezd_guard$
declare
  snap json;
  p record;
begin
  if coalesce(pg_catalog.current_setting('ezd.release_guard', true), '') <> 'on' then
    return;
  end if;
  execute <SNAP> into snap;
  select o.kind, o.name into p
    from ezd_release_guard.protected() as o
    left join (select e->>'id' as id, e->>'name' as name from pg_catalog.json_array_elements(snap) as e) as c on c.id = o.id
    where c.id is null or c.name <> o.name
    order by o.id
    limit 1;
  if found then
    raise exception 'ezd_release_guard: % % is dropped or renamed while % still reads it', p.kind, p.name, <TAG>;
  end if;
end
$ezd_guard$;
revoke all on function ezd_release_guard.protected() from public, anon, authenticated, service_role;
revoke all on function ezd_release_guard.on_sql_drop() from public, anon, authenticated, service_role;
revoke all on function ezd_release_guard.on_ddl_end() from public, anon, authenticated, service_role;
create event trigger ezd_release_guard_sql_drop on sql_drop execute function ezd_release_guard.on_sql_drop();
alter event trigger ezd_release_guard_sql_drop enable always;
create event trigger ezd_release_guard_ddl_end on ddl_command_end execute function ezd_release_guard.on_ddl_end();
alter event trigger ezd_release_guard_ddl_end enable always;
commit;
select 'ezd_release_guard_installed ' || (select pg_catalog.count(*) from ezd_release_guard.protected()) || ' ' || (select pg_catalog.count(*) from pg_catalog.pg_event_trigger where evtname in ('ezd_release_guard_sql_drop', 'ezd_release_guard_ddl_end') and evtenabled = 'A');
```
`<IDEXPR>` (the `SNAPSHOT_SQL` id forms `n`, `c`, `c<oid>:<attnum>`, `p`, `t`, `x`):
```sql
case r.classid when 'pg_catalog.pg_class'::pg_catalog.regclass then 'c' || r.objid || case when r.objsubid <> 0 then ':' || r.objsubid else '' end when 'pg_catalog.pg_proc'::pg_catalog.regclass then 'p' || r.objid when 'pg_catalog.pg_type'::pg_catalog.regclass then 't' || r.objid when 'pg_catalog.pg_namespace'::pg_catalog.regclass then 'n' || r.objid when 'pg_catalog.pg_extension'::pg_catalog.regclass then 'x' || r.objid end
```
Other classes give null and match nothing.

`GUARD_REMOVE_SQL` (no transaction; psql `ON_ERROR_STOP`):
```sql
select 'ezd_release_guard_before ' || (select pg_catalog.count(*) from pg_catalog.pg_event_trigger where evtname in ('ezd_release_guard_sql_drop', 'ezd_release_guard_ddl_end') and evtenabled = 'A');
drop event trigger if exists ezd_release_guard_sql_drop;
drop event trigger if exists ezd_release_guard_ddl_end;
drop schema if exists ezd_release_guard cascade;
select 'ezd_release_guard_removed ' || (select pg_catalog.count(*) from pg_catalog.pg_event_trigger where evtname in ('ezd_release_guard_sql_drop', 'ezd_release_guard_ddl_end')) || ' ' || (select pg_catalog.count(*) from pg_catalog.pg_namespace where nspname = 'ezd_release_guard');
```
`GUARD_SETTING_PROBE_SQL`: `select 'ezd_release_guard_setting ' || coalesce(pg_catalog.current_setting('ezd.release_guard', true), '');` plus `\n`.

### `createReleaseGuard({ sql })`
`SnapshotEntry` = `{ kind, name, id, ownedBy }`, all strings (EZD-153 S9); `parseSnapshot(text)` throws `Error('snapshot_unreadable')` on bad input. `retired` = base-tag entry objects `{ kind, name, ticket, reason }`. `install({ dbUrl, baseTag, retired })`, in order; any `sql` rejection in a step throws `ReleaseGuardError(<that step's code>, err)`:
1. `remove({ dbUrl })` (leftovers of a killed run); its error is rethrown as is (`remove_failed`).
2. `sql(GUARD_SETTING_PROBE_SQL, { dbUrl: withTimeouts(dbUrl, MIGRATION_TIMEOUTS, [RELEASE_GUARD_SETTING]) })`; trimmed stdout other than `ezd_release_guard_setting on` → `setting_not_applied`.
3. `sql(SNAPSHOT_SQL, { dbUrl })`; `parseSnapshot(stdout.trim())` throws or returns `[]` → `snapshot_unreadable`.
4. `objects = guardedObjects(entries, retired)`; `sql(buildGuardInstallSql({ objects, baseTag }), { dbUrl })`; trimmed stdout other than `ezd_release_guard_installed <objects.length> 2` → `install_failed`. Returns `{ protectedCount: objects.length }`.

`remove({ dbUrl })`: `sql(GUARD_REMOVE_SQL, { dbUrl })`; trimmed stdout must match `/^ezd_release_guard_before (\d+)\nezd_release_guard_removed 0 0$/`, else (or a rejection) `remove_failed`; returns `{ wasIntact: <captured number> === 2 }`.

### Step E (`release.mjs`, replaces the current E block inside `if (!alreadyLive)`)
Existing helpers of `runRelease`, used as they are: `git` (deps), `worktree()`, `childLines(err)` (prints `err.stderr` through `safeLines`; no `stderr` prints nothing), `stopV(code, built)` (summary `stoppedLine(code)` = `release stopped: <code> — nothing changed`), `partlyUpdated(code, err?)` (logs `code`, `childLines(err)`, summary `PARTLY_UPDATED_LINE(code, dumpPrefix)` = `release stopped: <code> — the live site is unchanged; the database may be partly updated; the dump from before this release is in <prefix>`). Both lines are generic over the code: no new map entry. Import `RETIRED_FILE`, `baseRetiredEntries` from `./check-migrations.mjs`; `createReleaseGuard`, `RELEASE_GUARD_SETTING` from `./release-guard.mjs`. The CLI's last line stays `release <code>`.
`guarded = base !== null` (`base` from step 8).
1. When guarded: no `deps.releaseGuard` → log `release_guard_failed: not_wired`, `return stopV('release_guard_failed', built)`. Else `retiredText` = `git(['show', `${base}:${RETIRED_FILE}`])`, `null` when that throws; `install({ dbUrl, baseTag: base, retired: baseRetiredEntries(retiredText) })`. Success → log `release guard on: <protectedCount> objects of <base>`. Throw → log `release_guard_failed: <err.code, else install_failed>`, `childLines(err)`, then `remove({ dbUrl })` (a throw logs `release_guard_remove_failed`), then `return stopV('release_guard_failed', built)`; push is not called.
2. `supabase.push({ dbUrl, workdir: worktree(), ...MIGRATION_TIMEOUTS, ...(guarded ? { settings: [RELEASE_GUARD_SETTING] } : {}) })` in `try { … } catch (err) { pushErr = err } finally { if (guarded) remove }`; the finally keeps `removeResult` or `removeErr`.
3. Outcome:

| push | remove | log, then return |
| --- | --- | --- |
| ok | `{ wasIntact: true }` | `release guard removed`; go on to F |
| ok | `{ wasIntact: false }` | `release guard removed`, `release_guard_failed: guard_lost`; `partlyUpdated('release_guard_failed')` |
| ok | throws | `release_guard_remove_failed`; `partlyUpdated('release_guard_failed', removeErr)` |
| fails | ok (either) | `release guard removed`; `partlyUpdated('migrate_failed', pushErr)` |
| fails | throws | `release_guard_remove_failed`; `partlyUpdated('migrate_failed', pushErr)` |

### Probe file (`supabase/checks/release-guard-probe.sql`, exactly)
```sql
-- EZD-241 (vault/plans/EZD-241.md; docs/runbook.md ## Cloud checks (EZD-171) J5): can postgres add an event
-- trigger that fires for its own changes? Paste all of it into the SQL Editor of ezdraft-dev and press Run.
-- It always ends in an error on purpose, so nothing it creates is kept. The error text must end with:
-- ezd_release_guard_probe user=postgres super=false fired=on
do $probe$
declare
  v_fired text;
  v_super text;
begin
  create schema ezd_release_guard_probe;
  create function ezd_release_guard_probe.mark() returns event_trigger language plpgsql set search_path = '' as $mark$
  begin
    perform pg_catalog.set_config('ezd.release_guard_probe', 'on', true);
  end
  $mark$;
  create event trigger ezd_release_guard_probe on ddl_command_end execute function ezd_release_guard_probe.mark();
  alter event trigger ezd_release_guard_probe enable always;
  create table ezd_release_guard_probe.t (id int);
  v_fired := coalesce(pg_catalog.current_setting('ezd.release_guard_probe', true), 'off');
  select case when r.rolsuper then 'true' else 'false' end into v_super from pg_catalog.pg_roles as r where r.rolname = current_user;
  raise exception 'ezd_release_guard_probe user=% super=% fired=%', current_user, v_super, v_fired;
end
$probe$;
```

| Choice | Decision | Source |
| --- | --- | --- |
| Session scope | Triggers act only when `current_setting('ezd.release_guard', true)` is `on`; only step E's push URL carries `-c ezd.release_guard=on` (startup `options`, after the timeouts). Fixed value: it scopes, it is no secret | Q-0358 (c); EZD-146 L2 |
| Setting reaches the pooled session | Proven per run by `install` step 2 over the same URL before anything is created; else `setting_not_applied` | step B pattern (`migrate_timeouts_not_applied`); R-019 |
| Protected set | Production's `SNAPSHOT_SQL` rows at the start of step E minus `isRetired(base-tag retired entries, { kind, name })`, matched by object id and name: rename, `set schema`, drop, drop and re-create are refused; objects this release creates are free | EZD-153 `compareStep` M1; check-migrations.mjs lines 334-335; L-014 |
| Granularity | Per DDL statement (stricter than EZD-153's per file) | architecture Release safety "stricter, never weaker" |
| Both triggers | `sql_drop` names a dropped object at once; `ddl_command_end` catches renames and `set schema` | Q-0358 (c) |
| `enable always` | Both, so `session_replication_role = replica` cannot skip them | planner run |
| Leftovers | `install` removes earlier guard objects first (a killed runner never ran its finally) | AC-EZD-241-2 |
| Trigger dropped or disabled by a migration | Such commands fire no event trigger, so `remove` counts the enabled guard triggers; fewer than 2 after a good push is `guard_lost`, nothing goes live | CLAUDE.md rule 18 |
| No base tag | No guard; push without `settings` | architecture Release safety "No tag yet" |
| Dev pushes | `scripts/db/dev-push.mjs` unchanged (no `settings`) | Q-0110 |
| Missing dependency | `deps.releaseGuard` absent with a base tag → `release_guard_failed` before push | CLAUDE.md rule 18 |
| Setting validation | name `/^[a-z][a-z0-9_]*\.[a-z][a-z0-9_]*$/`, value `/^[a-z0-9_]+$/`, else `Error('invalid_setting')` with `code`; empty `settings` keeps the URL byte-identical | push.mjs `db_url_has_options` |

| `ReleaseGuardError` | `extends Error`; `name` `'ReleaseGuardError'`; `message` = `code` (`remove_failed`, `setting_not_applied`, `snapshot_unreadable`, `install_failed`); `stderr` = the rejection's `stderr` string, else `''` | release.mjs `childLines` |
| Child output | Only through `childLines` (safeLines over the mask list) | EZD-152 |
