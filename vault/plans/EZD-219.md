# EZD-219 · Status bar popovers

- **ACs:** AC-EZD-219-1, AC-EZD-219-2, AC-EZD-219-3, AC-EZD-219-4, AC-EZD-219-5 (`vault/spec/acceptance-criteria.md:1020-1024`, stage-0)

- **User-visible result:** The plan's status bar shows Scale, Snap, the live cursor position and the zoom. Clicking Snap turns each snap kind on or off and sets the snap step; clicking Scale picks the plan scale, which the project remembers; clicking the zoom lets you type a zoom.

Prefixes: `A/` = `app/src/`, `T/` = `app/test-harness/`. Run commands from the repo root.
