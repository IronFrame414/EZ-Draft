CSS helper in `touch-css.test.ts` (test-author writes it there): `cssRules(text)` strips `/* … */`, normalizes whitespace to single spaces and `"` to `'`, then scans braces with a depth counter and returns, in file order, `{ media: string \| null, sel: string, decls: string[] }` for every style rule, where `media` is the trimmed prelude of the enclosing `@media` block (for example `@media (hover: hover)`) or `null`, and `decls` are `name: value` strings split on `;` and trimmed. `first(rules, sel)` = first rule with that `sel`; `inMedia(rules, sel, media)` = the rule with that `sel` and that `media`.
