### Contract between the parts
Part a fixes, and part b uses unchanged: `GET /api/settings/system-status?part=jobs|webhooks|backups[&page=<1..999999>]` answering 200 `StatusPage<JobFailureRow>`, `StatusPage<WebhookFailureRow>` or `BackupStatus`, 400 `invalid_input`, 401 `not_signed_in`, 403 `permission_denied` / `error.not_authorized`, 500 `db_unavailable`, all `Cache-Control: no-store`; and from `app/src/lib/system-status/system-status.ts` the types `StatusPart`, `StatusQuery`, `StatusPage<T> = { rows, total, page, pageSize }`, `JobFailureRow = { id, kind, error, attempts, finishedAt }`, `WebhookFailureRow = { id, title, ref, occurrences, lastSeenAt }`, `BackupRow = { finishedAt, bytesCopied, location }`, `DrillRow = BackupRow & { status: 'succeeded' | 'failed' }`, `BackupStatus = { files, dbDump, restoreDrill }` (each nullable), and the constants `SYSTEM_STATUS_PAGE_SIZE = 50`, `JOB_FAILURE_DAYS = 30`, `SYSTEM_STATUS_PATH = '/settings/system-status'` (exact signatures: 6a0539ee section 3). Part b only adds `formatStatusTime` and `formatBytes` to that file and changes nothing part a exports.
