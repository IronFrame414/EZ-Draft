- **ACs:** AC-EZD-5601-1, AC-EZD-5601-2, AC-EZD-5601-3, AC-EZD-5601-4, AC-EZD-5601-5, AC-EZD-5601-6, AC-EZD-5601-7, AC-EZD-5601-8, AC-EZD-5601-9, AC-EZD-5601-10

- **User-visible result:** In My profile, every signed-in user pastes their own Anthropic API key; it is checked with Anthropic, stored encrypted, shown as "Key saved · ends in" and its last 4, and Remove deletes it; an email confirms each add and remove.

## 1. What to build

Data (Q-0637 key-storage row, decisions 10; `docs/architecture.md` Row-level security (EZD-006), Migrations). Three migrations, timestamps taken after the newest file in `supabase/migrations/` on develop at merge time (L-060), consecutive, one concern each. SQL below is contract text: **confirm on pinned version** (L-009) by running `pnpm db:up` and the step's verify command before the tests are committed.

- **M1 `<ts>_create_user_ai_key.sql`:** `public.user_ai_key (tenant_id uuid not null references public.tenant (id) on delete cascade, app_user_id uuid not null references public.app_user (id) on delete cascade, ciphertext text not null check (char_length(ciphertext) between 40 and 512 and ciphertext ~ '^[A-Za-z0-9+/]+={0,2}$'), secret_version integer not null check (secret_version between 1 and 999999), last4 text not null check (last4 ~ '^[!-~]{4}$'), created_at timestamptz not null default now(), updated_at timestamptz not null default now(), primary key (tenant_id, app_user_id))`; index `user_ai_key_app_user_id_idx (app_user_id)`; trigger `user_ai_key_set_updated_at before update … execute function public.set_updated_at()`; RLS on; policy `user_ai_key_none for all to authenticated using (tenant_id = (select private.tenant_id()) and false) with check (tenant_id = (select private.tenant_id()) and false)`; `revoke all on public.user_ai_key from public, anon, authenticated; grant select, insert, update, delete on public.user_ai_key to service_role;`.
- **M2 `<ts+1>_create_ai_key_attempt.sql`:** `public.ai_key_attempt (id uuid primary key default gen_random_uuid(), tenant_id uuid not null references public.tenant (id) on delete cascade, app_user_id uuid not null references public.app_user (id) on delete cascade, at timestamptz not null default now())`; indexes `ai_key_attempt_tenant_user_at_idx (tenant_id, app_user_id, at)`, `ai_key_attempt_at_idx (at)`, `ai_key_attempt_app_user_id_idx (app_user_id)`; RLS, policy, revoke and grant exactly as M1 with the table name `ai_key_attempt` (policy `ai_key_attempt_none`).
- **M3 `<ts+2>_create_user_ai_key_functions.sql`:** every function `security definer`, `set search_path = ''`, first statement `perform private.require_api_gate();` (public ones), then `revoke all on function … from public, anon, service_role; grant execute on function … to authenticated;` (L-016). `v_user := private.app_user_id(); v_tenant := private.tenant_id();` in each.
  - `public.get_my_ai_key() returns table (tenant_id uuid, app_user_id uuid, last4 text, secret_version integer, ciphertext text)`, `stable`: `v_user` null → `raise exception 'permission_denied' using errcode = '42501'`; returns exactly one row `select v_tenant, v_user, k.last4, k.secret_version, k.ciphertext from (select 1) one left join public.user_ai_key k on k.tenant_id = v_tenant and k.app_user_id = v_user` (key columns null when no row or `v_tenant` null).
  - `public.save_my_ai_key(p_tenant_id uuid, p_app_user_id uuid, p_ciphertext text, p_secret_version integer, p_last4 text) returns void`, `volatile`: 42501 when `v_user` or `v_tenant` is null, `p_tenant_id is distinct from v_tenant`, `p_app_user_id is distinct from v_user`, or no `public.membership` row `(tenant_id = v_tenant, user_id = v_user, status = 'active')`; `22023 invalid_input` when any value fails M1's column checks or is null; then `insert … on conflict (tenant_id, app_user_id) do update set ciphertext = excluded.ciphertext, secret_version = excluded.secret_version, last4 = excluded.last4`.
  - `public.delete_my_ai_key() returns table (deleted boolean, last4 text)`, `volatile`: 42501 when `v_user` or `v_tenant` null; `delete … where k.tenant_id = v_tenant and k.app_user_id = v_user returning k.last4 into v_last4`; returns `(v_last4 is not null, v_last4)`.
  - `public.take_ai_key_attempt() returns boolean`, `volatile`: 42501 when `v_user` or `v_tenant` null; `perform 1 from public.app_user u where u.id = v_user for update;` (cap lock before the count, EZD-321); `delete from public.ai_key_attempt a where a.at < now() - interval '15 minutes';` count rows `(v_tenant, v_user)` with `at > now() - interval '15 minutes'`; `>= 5` → `return false`; else insert `(v_tenant, v_user)` and `return true`.
  - `public.rewrap_my_ai_key(p_old_version integer, p_ciphertext text, p_secret_version integer) returns boolean`, `volatile`: 42501 as delete; 22023 as save's checks or `p_secret_version <= p_old_version`; `update … set ciphertext, secret_version where tenant, user and k.secret_version = p_old_version`; returns `found`.
  - `private.membership_drop_ai_key() returns trigger` (no API role executes it; `revoke all … from public`): on `DELETE` deletes the `(old.tenant_id, old.user_id)` key row and returns `old`; on `UPDATE` deletes it when `new.status <> 'active' or new.user_id is distinct from old.user_id or new.tenant_id is distinct from old.tenant_id`, returns `new`. Trigger `membership_drop_ai_key after update or delete on public.membership for each row`.
- No money field (Q-0637 usage row: the user's own bill is not in `MONEY_FIELDS`). No `schema_version` change.
