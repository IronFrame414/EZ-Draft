## 4. Tests
All in `root-lint.test.mjs`. `root` = the repo root (three levels up, as `no-polling-lint.test.mjs`). Spawns: `spawnSync('pnpm', ['exec', 'eslint', ...args], { cwd: root, encoding: 'utf8', env: childEnv(), maxBuffer: 64 * 1024 * 1024 })`, plus `input` = the row's input in T2-T4 only (`--stdin` with a `--stdin-filename` that does not exist on disk is matched against the config by path; planner run at BASE gave the T2-T4 results), `childEnv()` copied from `no-polling-lint.test.mjs` (pnpm on `PATH`, as its T18 (g)); every spawn test first asserts `r.error` is `undefined`, so a spawn failure fails the test. `noUndef(code, filePath)` = `new ESLint({ cwd: root }).lintText(code, { filePath })` (ESLint from `importFromRoot('eslint')`), returning the messages whose `ruleId` is `no-undef`. Probe paths are never written to disk.
