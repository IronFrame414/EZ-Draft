### Decided for the builder
| Choice | Decision | Source |
| --- | --- | --- |
| URL rule | `isSiteUrl(text)`: `new URL(String(text))` inside `try`; any throw is `false`. `true` only when `protocol === 'https:'`, `host === HOST` (`host` includes a port, so any explicit port fails; the default 443 is dropped by the parser), `username === ''` and `password === ''`. Path, query and hash are not compared. | ticket Scope ("compare the redirect Location's protocol and host exactly (URL parse)"); WHATWG URL parsing (Node built-in `URL`) |
| Relative or missing Location | `new URL('/')` and `new URL('undefined')` throw, so a relative or absent Location fails `redirect` | same rule |
| Host letter case | The parser lower-cases the host, so `https://EZDRAFT.ezcontractorbinder.com/` passes; DNS names are case-insensitive | WHATWG URL host parsing |
| `host` check uses the same rule | Yes: today it compares `hostname`, so a port slips through the same way; one rule for both checks, never weaker than today | ticket title ("match what they claim"); CLAUDE.md rule 17 |
| Detail strings | Unchanged: `final url <finalUrl>`, `http <status> <location>` | EZD-003 contract (section 3) |
| `observe`, CLI output, exit codes | Unchanged | EZD-003 contract; scripts/release/release.mjs line 34 and 689 import `evaluate`, `HOST`, `observe` |
| New dependency | None; Node built-ins only | EZD-003 contract (`check-live.mjs`: Node built-ins only) |
| Command shell | The (a) command uses POSIX `sh` only (`[ ]`, `&&`, `;`, `exit`), no bash-only syntax; Vercel's docs do not name the shell | R-023 |
| Exit code meaning | Exit 1 = Vercel builds; exit 0 = Vercel skips (cancels) | R-023 (Vercel KB, Ignored Build Step field) |
| Why (a) matches the source branch, not the target | Vercel gives no variable for a pull request's target branch; `VERCEL_GIT_COMMIT_REF` is the pushed branch, so "the phase PR" is read as "a pull request whose branch is `develop`" | R-023 (System environment variables) |
