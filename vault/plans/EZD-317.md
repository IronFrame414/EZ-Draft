## 3. Interface contract
| # | Kind | Name or path | Details |
| --- | --- | --- | --- |
| C1 | function (local) | `excludedProblems(entries: string[], denyScripts: string): string[]` in scripts/process/sandbox-coverage.test.mjs | denyScripts = the one absolute denyWrite entry ending `/scripts` (as the existing D-012 test finds it). An entry is ok when it matches `^node (\S+)( [a-z-]+)? \*$`, `path.normalize($1) === $1`, `$1` starts with `denyScripts + '/'`, ends `.mjs`, and has none of `*?~`; else one line `<entry>: not write-denied` |
| C2 | export | `excludedPrefix(scriptsDir: string, tail: string): string` in scripts/excluded-form.mjs | reads `path.join(scriptsDir, 'unit-sandbox.json')`; returns the first `sandbox.excludedCommands` string that starts `node /` and ends `` `/scripts/${tail} *` ``, minus the last 2 characters; a missing or unparsable file, a non-array, or no match returns `` `node scripts/${tail}` ``. Never throws; imports `node:fs`, `node:path` only; contains no `SANDBOX STOP` text |
| C3 | STOP text | gate.mjs, ui-run.mjs, unit-steps.mjs | the command inside the backticks is `excludedPrefix(…) + ' ' + <args>`; the rest of each line unchanged |
