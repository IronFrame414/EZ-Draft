## 1. What to build

Data: new table `benchmark_run` (03e; Q-0664 03-data-model). No money field. Reads and writes only through two definer functions; `authenticated` holds no table privilege.

**M1** `supabase/migrations/<ts>_create_benchmark_run.sql`, `<ts>` later than the newest migration on develop at merge time (L-060; newest today `20261109100000`). Confirm on pinned version (L-009): none of this SQL has been run.
- Table: `id uuid pk default gen_random_uuid()`; `tenant_id uuid not null references public.tenant (id) on delete cascade`; `created_by uuid null references public.app_user (id) on delete set null`; `device jsonb not null check (jsonb_typeof(device) = 'object')`; `app_version text not null check (char_length(app_version) between 1 and 64)`; `results jsonb not null check (jsonb_typeof(results) = 'object')`; `run_at timestamptz not null default now()`.
- Index `benchmark_run_tenant_run_at_idx on (tenant_id, run_at desc, id desc)` (11 rule 10; audit needs `tenant_id` first, `app/test-harness/rls/audit.ts:152`).
- RLS on. Policy `benchmark_run_select` for select to authenticated using `tenant_id = (select private.tenant_id()) and exists (select 1 from public.user_permission up where up.membership_id = nullif((select auth.jwt()) ->> 'membership_id', '')::uuid and up.tenant_id = (select private.tenant_id()) and up.permission_key = 'settings_system_status' and up.granted)`. Restrictive policy `benchmark_run_api_gate` for all to authenticated, using and with check `(select private.require_api_gate())` (pattern `20261107180000_create_sync_conflict.sql`).
- `revoke all on public.benchmark_run from public, anon, authenticated;` `grant select, insert, update, delete on public.benchmark_run to service_role;` `comment on table public.benchmark_run is 'Data model entity: benchmark_run (EZD-237)';`
- **F1** `public.record_benchmark_run(p_device jsonb, p_app_version text, p_results jsonb) returns uuid`, plpgsql volatile security definer `set search_path = ''`. Steps, first failure wins: (1) `perform private.require_api_gate()`; (2) `v_tenant := private.tenant_id()`, `v_membership := nullif(auth.jwt() ->> 'membership_id','')::uuid`, `v_user := private.app_user_id()`; any null → `raise exception 'permission_denied' using errcode = '42501'`; (3) fewer than 2 granted rows in `public.user_permission` for `v_membership`, `v_tenant`, keys `settings_system_status` and `edit_model` → 42501 (Q-0664 05-screens); (4) `p_device` or `p_results` null or not `jsonb_typeof = 'object'`, or `p_app_version` null or length outside 1–64 → `raise exception 'invalid_input' using errcode = '22023'`; (5) insert `(tenant_id, created_by, device, app_version, results)` = `(v_tenant, v_user, p_device, p_app_version, p_results)` returning `id`.
- **F2** `public.list_benchmark_runs(p_page integer) returns jsonb`, plpgsql stable security definer `set search_path = ''`. (1) gate; (2) tenant and membership as F1 (no `app_user` needed); (3) no granted `settings_system_status` row → 42501; (4) `p_page` null, `< 1` or `> 1000000` → 22023; (5) returns `jsonb_build_object('total', <count of the tenant's rows>, 'rows', coalesce(jsonb_agg(...), '[]'::jsonb))`, each row `jsonb_build_object('id', id, 'run_at', run_at, 'device', device, 'app_version', app_version, 'results', results)` from the tenant's rows `order by run_at desc, id desc limit 50 offset (p_page - 1) * 50`, aggregated in that order (Q-0664; 11 rule 9).
- Both: `revoke all on function … from public, anon, service_role;` then `grant execute … to authenticated;` (L-016; `20261106140002_create_benchmark_project_function.sql:65-66`).
