## 1. What to build

**Pick (Q-0315 lets the planner choose): browser sign-ins leave the seeded rows as found.** Playwright's global teardown deletes the auth users of the five seeded people, which unlinks their `app_user` rows (`auth_user_id ... on delete set null`, `supabase/migrations/*_create_app_user.sql` line 6), then checks none is still linked. EZD-005b T17 (e) itself is not changed. Evidence:
- E1. Four tests, not one, assert a seeded row is unlinked: `scripts/db/__tests__/tenancy-bootstrap.test.mjs` T17 (e) (`j.user.auth_user_id` null), `app/src/server/db/seed.test.ts` lines 43 (EZD-005b done when) and 101 (EZD-016c done when), `app/src/server/auth/sign-in.test.ts` line 308 (EZD-007d T5). - E5. Pinned Playwright 1.64.1 runs `globalTeardown` once after all workers (`node_modules/.pnpm/playwright@1.64.1/node_modules/playwright/types/test.d.ts` line 1408), so no test is signed in as a seeded person while it runs; a per-test cleanup would end a session another worker still uses (4 workers, Q-0114).

Step 1, `restoreSeededUsers(users, deleteAuthUser)`, in order:
1. `users.length === 0`: return; no query, no delete.
2. `emails` = `users.map((u) => u.email.toLowerCase())`; `ids` = `users.map((u) => u.id)`.
3. Auth user ids to delete, through `harnessSql()` (`app/test-harness/rls/fixtures.ts`; postgres.js tagged template: pass the JS string arrays straight in as `${emails}::text[]` and `${ids}::uuid[]`, as `cleanupCreated` does with `any(${refs.tenantIds}::uuid[])`; no `sql.array`; the result is an array of `{ id: string }` rows): `select id::text as id from auth.users where lower(email) = any(${emails}::text[]) union select auth_user_id::text as id from public.app_user where id = any(${ids}::uuid[]) and auth_user_id is not null`; sort ascending; remove duplicates.
4. For each id in that order, one at a time: `await deleteAuthUser(id)`; an error propagates and stops the loop.
5. Check, through `harnessSql()`: `linked` = `select id::text as id from public.app_user where id = any(${ids}::uuid[]) and auth_user_id is not null order by id`; `left` = `select count(*)::int as n from auth.users where lower(email) = any(${emails}::text[])`.
6. `linked.length > 0` or `left > 0`: throw `new Error(`seeded users not restored: linked ${linkedIds.join(',') || 'none'}, auth users left ${left}`)`; else resolve.

Step 1, `deleteAuthUserOrThrow(id)`: `const { error } = await adminDb().auth.admin.deleteUser(id)`; on `error` throw `new Error(`restore of seeded users failed: deleteUser ${error.code ?? error.status}`)`.

Step 1, `SEEDED_USERS`, in this order, from `app/test-utils/seed-ids.ts` exports (never literals): `{ id: JOSH_USER_ID, email: JOSH_EMAIL }`, `{ id: DESIGNER_USER_ID, email: DESIGNER_EMAIL }`, `{ id: FOREMAN_USER_ID, email: FOREMAN_EMAIL }`, `{ id: CREW_USER_ID, email: CREW_EMAIL }`, `{ id: TENANT_2_OWNER_USER_ID, email: TENANT_2_OWNER_EMAIL }`; `Object.freeze` on the array and on each entry.
