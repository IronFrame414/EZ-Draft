Step 1, read route, in this order inside the existing `try` (D1–D4):
1. `const p = await requireApiPermission('view_projects');` (inside the existing `try`, so a throw reaches the existing `catch` → `dbUnavailable()`; no new try/catch) then `if (p instanceof Response) return p;` (401 `not_signed_in`, 403 `permission_denied`). This replaces the `requireApiSession()` call; remove the now unused `requireApiSession` import.
2. `const { id } = await params;` not `z.uuid()` → `notFound()` (unchanged).
3. The existing session-client select, `if (error) throw error;`, no row → `notFound()` (unchanged).
4. New: `if (data.project_id !== null && !can(p.ctx, 'view_projects', { projectId: data.project_id })) return notFound();`
5. The 200 body, field list and headers unchanged; the `catch` → `dbUnavailable()` unchanged.

Import `can` and `requireApiPermission` from `'../../../../server/permissions'` (EZD-102 `index.ts`).

Step 2, dev route, in this order (D1, D2, D5–D7):
1. `VERCEL_ENV === 'production'` → bare 404 (unchanged, first).
2. `let p: Permitted | Response;` `try { p = await requireApiPermission(DEV_JOB_PERMISSION); } catch { return dbUnavailable(); }` (`dbUnavailable` is the route's existing local helper; this block takes the place of the existing `requireApiSession` try/catch) then `if (p instanceof Response) return p;` (401, 403). This replaces the `requireApiSession()` block; remove the unused import.
3. Body parse with `bodySchema` → 400 `invalid_input` (unchanged).
4. New: `const denied = requirePermission(p.ctx, DEV_JOB_PERMISSION, { projectId }); if (denied) return denied;` (404 `project_not_found` for a listed member's unlisted project).
5. `enqueueJob` and its `catch` mapping (400 `invalid_payload`, 404 `job_not_found` on `42501`, 500) unchanged.

`DEV_JOB_PERMISSION` is a module-level `const DEV_JOB_PERMISSION: PermissionKey = 'view_projects';` (not exported), the value QP-1 decides.
