| D-Read | `compute(read, key)` gets a recording wrapper of the source. Every `read.object(id)` call records `{ id, value }` (the returned reference, `null` included). Repeated reads are recorded again; nothing is deduplicated. | ticket Scope ("cached by the object ids they read"); glossary 00g "Derived value" |
| D-Valid | An entry is valid against a source when it was last checked against that same source object, or when every recorded `object(id)` read returns the same reference now (`null` equals `null`) and every recorded `objectsOf(type, level)` read returns an array of the same length with the same reference at every index. A valid entry is a hit and then records that source as last checked. | D-Errors | A compute that throws: the error is rethrown to the `get` caller unchanged, `computes[name]` counts the attempt, and no entry is kept for that key (an old invalid one is deleted). A `get` called while a compute is running (on any key of the same cache) throws `new Error('derived_nested_get')`, is not counted, and leaves the running compute to finish or throw. The running flag is cleared in `finally`. A compute returning `undefined` is cached like any value. Order inside `get`: (1) a running compute → `derived_nested_get`; (2) the D-Name check, which registers a name the first time it is seen; (3) the entry lookup and D-Valid; (4) the compute.
