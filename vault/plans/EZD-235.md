### Decided for the builder
| Choice | Decision | Source |
| --- | --- | --- |
| D-Where | Cache and derived definitions are pure TypeScript in G (no DOM), so workers and the server can run them; the store binding is in `A/editor/derived/` | ticket Scope; 11 Where each output is produced; ARCH Folder layout |
| D-Pull | Computing happens only inside `get`; an edit never recomputes, it only changes what the next `get` sees. A value nobody asks for is never computed | ticket Scope; 11 rule 2; AC-2 |
| D-Valid | An entry is valid when each `object(id)` it read returns the same reference now (`null` equals `null`) and each `objectsOf(type, level)` it read returns an array of the same length with the same reference at every index; else `get` recomputes and replaces it. Never uses `lastChangedIds` (`applySavedNumbers` in `A/editor/model/model-store.ts` changes objects without it) | ticket Scope; CLAUDE.md rule 18 |
| D-Key | Entry key `` `${def.name}\u0000${key}` ``; `key` = the object's `Objects` map key | K1 |
| D-Identity | One `WeakMap<ObjectValue, ModelObject \| null>` per `ModelDerived`; each value parsed once with `parseStoredObject`. `applyEditTo` keeps untouched values' identity, so unchanged objects keep their parsed reference | ARCH Patch store and outbox |
| D-Source | A new source when `store.getState().objects` is a different map from the last, else the last one. `objectsOf` is built on first call per `(type, level)` per source, in map insertion order, level compared case-insensitively; floors are excluded from `type` (no level, ARCH Model schema) | Q-0664 (EZD-216 reads all walls of a level) |
| D-Errors | A throwing compute: error propagates, nothing cached, `computes[name]` counts it. `get` inside a compute throws `Error('derived_nested_get')`, not counted | ARCH Errors and logging |
| D-Prune | `prune` drops entries with an `object(id)` read that was non-null when recorded and is `null` now; returns the count. The plan controller prunes after each rebuild | 11 Also (iPad memory) |
| D-Room | `ROOM_AREA.name` = `'room-area'`; reads `object(key)` only: a room → `roomAreaSqFt(boundary)`, else `null`. `ModelDerived.roomAreaSqFt(room)` falls back to uncached `roomAreaSqFt(boundary)` on `null` | ARCH Rooms (area derived, never stored); 09j Room area; Q-0207; Q-0568 |

| D-Pool | Workers start on the first `run`, never at load (a worker script fetched at load counts in `js-size`); one job per worker; FIFO queue; job ids from 1 per pool; unknown reply ids ignored; idle workers kept until `dispose` | ARCH Performance check (What JavaScript counts); 11 rule 3 |
