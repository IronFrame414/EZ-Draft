# EZD-042 · Fix: Supabase CLI dump and push pass the production database URL as --db-url

- **ACs:** AC-EZD-042-1, AC-EZD-042-2
- **Complexity:** medium (section 8)
- **User-visible result:** nothing changes on screen; the release and the weekly backup no longer put the production database password on the `supabase` command line, where other processes on the runner could read it.
- Phase: 0 · Planned by: planner · Date: 2026-10-23 · Status: planned

## 1. What to build

Scope from the ticket row (phase-00.md EZD-042): `dump.mjs:90`, `push.mjs:25` and `:31` put the URL with its password in `--db-url`. The fix: `--db-url` keeps the URL minus its password; the password goes to the CLI child only as `PGPASSWORD` in its env (D1, D2). No data, no migration, no screen.
